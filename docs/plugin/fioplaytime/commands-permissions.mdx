# Commands & Permissions

This page was scanned from `plugin.yml`, `README.md`, `PlaytimeCommand.java`, and `FioPlaytimeCommand.java`.

## Root commands

The plugin registers two root commands:

- `/playtime`
- `/fioplaytime`

Aliases:

- `/ptime`
- `/fpt`

## User commands

| Command | Permission | Description |
| --- | --- | --- |
| `/playtime` | `fioplaytime.menu` | Open the main playtime menu. |
| `/playtime [player]` | `fioplaytime.playtime.others` | Show another player's playtime in chat. |
| `/fioplaytime` | `fioplaytime.menu` | Open the main playtime menu. |
| `/fioplaytime info` | `fioplaytime.info.self` | Show your own playtime information. |
| `/fioplaytime info [player]` | `fioplaytime.info.others` | Show another player's playtime information. |
| `/fioplaytime help` | `fioplaytime.help` | Show player help. |
| `/fioplaytime toggle notification` | `fioplaytime.toggle.notification` | Toggle reward notification messages. |
| `/fioplaytime toggle bossbar` | `fioplaytime.toggle.bossbar` | Toggle the playtime bossbar. |
| `/fioplaytime claim [tier]` | `fioplaytime.claim` | Claim one available playtime reward tier. |
| `/fioplaytime claimall` | `fioplaytime.claimall` | Claim every available unclaimed reward tier. |
| `/fioplaytime leaderboards` | `fioplaytime.leaderboards` | Open the playtime leaderboard menu. |
| `/fioplaytime materials` | `fioplaytime.materials` | Open the material selector menu. |
| `/fioplaytime reload` | `fioplaytime.reload` | Reload plugin files from a shortcut command. |
| `/fioplaytime status [player]` | `fioplaytime.status` | Show runtime tracking status for yourself or a player. |

## Admin commands

Admin commands use `/fioplaytime admin ...`.

| Command | Permission | Description |
| --- | --- | --- |
| `/fioplaytime admin info [player]` | `fioplaytime.admin.info` | Show stored playtime data for a player. |
| `/fioplaytime admin blacklist add [player]` | `fioplaytime.admin.blacklist.add` | Stop a player from being tracked. |
| `/fioplaytime admin blacklist remove [player]` | `fioplaytime.admin.blacklist.remove` | Remove a player from blacklist. |
| `/fioplaytime admin blacklist list` | `fioplaytime.admin.blacklist.list` | List blacklisted players. |
| `/fioplaytime admin freeze add [player]` | `fioplaytime.admin.freeze.add` | Freeze a player's playtime progress. |
| `/fioplaytime admin freeze remove [player]` | `fioplaytime.admin.freeze.remove` | Unfreeze a player. |
| `/fioplaytime admin freeze list` | `fioplaytime.admin.freeze.list` | List frozen players. |
| `/fioplaytime admin time add [player] [value]` | `fioplaytime.admin.time.add` | Add playtime to a player. |
| `/fioplaytime admin time remove [player] [value]` | `fioplaytime.admin.time.remove` | Remove playtime from a player. |
| `/fioplaytime admin time set [player] [value]` | `fioplaytime.admin.time.set` | Set a player's playtime. |
| `/fioplaytime admin player [player/all] reset` | `fioplaytime.admin.player.reset` | Reset one player or every player's playtime data. |
| `/fioplaytime admin player [player] tier set [value] [status]` | `fioplaytime.admin.player.tier.set` | Set a player's tier state. |
| `/fioplaytime admin player [player] tier remove [value] [status]` | `fioplaytime.admin.player.tier.remove` | Remove a tier state from a player. |
| `/fioplaytime admin player [player] tier add [value] [status]` | `fioplaytime.admin.player.tier.add` | Add a tier state to a player. |
| `/fioplaytime admin reload` | `fioplaytime.admin.reload` | Reload plugin-managed files. |
| `/fioplaytime admin placeholders` | `fioplaytime.admin.placeholders` | Show available PlaceholderAPI placeholders. |
| `/fioplaytime admin help` | `fioplaytime.admin.help` | Show admin help. |
| `/fioplaytime admin authors` | `fioplaytime.admin.authors` | Show plugin author. |
| `/fioplaytime admin open [player] [menu] [arg]` | `fioplaytime.admin.open` | Open a configured menu for a target player. |
| `/fioplaytime admin forceOpen [player] [menu] [arg]` | `fioplaytime.admin.forceopen` | Force-open a menu for a target player. |

## Duration values

Admin time commands parse comma-separated durations:

- `10s`
- `5m`
- `2h`
- `3d`
- `1w`
- `1mo`
- `1y`
- `1h,30m,10s`

:::info[Page note]
Tier status tab-completion includes `unlocked`, `locked`, `freeze`, and `onprogress`.
:::
