# Monster Hunt

`monster_hunt.yml` defines a competitive hunting quest.

| Field | Value |
| --- | --- |
| Quest id | `monster_hunt` |
| Name | `<red>Monster Hunt</red>` |
| Material | `IRON_SWORD` |
| Mode | `comp` |
| Duration | `1d` |
| Objective type | `HUNT` |
| Goal | `30000` |

## Objective behavior

`HUNT` counts matching entity kills. Global settings can prevent spawned or spawner-based mobs from counting.
