# Netherite Smithing

`netherite_smithing.yml` defines a competitive smithing quest.

| Field | Value |
| --- | --- |
| Quest id | `netherite_smithing` |
| Name | `<dark_gray>Netherite Smithing</dark_gray>` |
| Material | `SMITHING_TABLE` |
| Mode | `comp` |
| Duration | `2d` |
| Objective type | `SMITHING` |
| Goal | `1000` |

## Objective behavior

`SMITHING` counts matching smithing table results, such as upgrading or creating netherite gear.
