# Wool Shearing Drive

`wool_shearing.yml` defines a cooperative shearing quest.

| Field | Value |
| --- | --- |
| Quest id | `wool_shearing` |
| Name | `<white>Wool Shearing Drive</white>` |
| Material | `SHEARS` |
| Mode | `coop` |
| Duration | `1d` |
| Objective type | `SHEARING` |
| Goal | `15000` |

## Objective behavior

`SHEARING` counts matching shearing results, especially wool variants from sheep.
