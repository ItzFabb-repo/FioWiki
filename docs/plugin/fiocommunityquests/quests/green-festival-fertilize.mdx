# Green Festival

`green_festival_fertilize.yml` defines a cooperative fertilizing quest.

| Field | Value |
| --- | --- |
| Quest id | `green_festival_fertilize` |
| Name | `<green>Green Festival</green>` |
| Material | `BONE_MEAL` |
| Mode | `coop` |
| Duration | `12h` |
| Objective type | `BLOCK_FERTILIZE` |
| Goal | `25000` |

## Objective behavior

`BLOCK_FERTILIZE` counts fertilizing configured crops or plants with bone meal.
