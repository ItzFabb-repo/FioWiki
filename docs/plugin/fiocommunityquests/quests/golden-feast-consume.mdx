# Golden Feast

`golden_feast_consume.yml` defines a competitive consume quest.

| Field | Value |
| --- | --- |
| Quest id | `golden_feast_consume` |
| Name | `<gold>Golden Feast</gold>` |
| Material | `GOLDEN_APPLE` |
| Mode | `comp` |
| Duration | `8h` |
| Objective type | `CONSUME` |
| Goal | `10000` |

## Objective behavior

`CONSUME` counts matching consumed food or drink items, for example golden apples.
