# RESSURECTION

`RESSURECTION` adds progress when a player is saved by a totem of undying.

## Format

```yaml
quest:
  objectives:
    type: "RESSURECTION"
    goal: 10
    required:
      - TOTEM_OF_UNDYING
```

## Required values

Current source progress target:

- `TOTEM_OF_UNDYING`

## Notes

The source uses the spelling `RESSURECTION`. Legacy aliases `RESURRECTION`, `TOTEM_POP`, and `TOTEM_OF_UNDYING` are normalized to this type.
