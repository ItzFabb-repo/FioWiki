# Arcane Enchanters

`arcane_enchanters.yml` defines a competitive enchanting quest.

| Field | Value |
| --- | --- |
| Quest id | `arcane_enchanters` |
| Name | `<light_purple>Arcane Enchanters</light_purple>` |
| Material | `ENCHANTING_TABLE` |
| Mode | `comp` |
| Duration | `1d` |
| Objective type | `ENCHANTING` |
| Goal | `800` |

## Objective behavior

`ENCHANTING` counts matching enchantments and minimum levels. Tool filters can use `ANY`, exact material names, or wildcard patterns such as `*_SWORD`.
