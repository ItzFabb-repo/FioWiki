# Community Builder

`community_builder_block_place.yml` defines a cooperative block placement quest.

| Field | Value |
| --- | --- |
| Quest id | `community_builder_block_place` |
| Name | `<gold>Community Builder</gold>` |
| Material | `OAK_PLANKS` |
| Mode | `coop` |
| Duration | `1d` |
| Objective type | `BLOCK_PLACE` |
| Goal | `50000` |

## Objective behavior

`BLOCK_PLACE` adds progress when a player places configured block materials. Global and per-quest restrictions can prevent progress in blocked worlds, regions, gamemodes, or player lists.
