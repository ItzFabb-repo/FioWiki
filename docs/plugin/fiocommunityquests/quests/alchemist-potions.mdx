# Potion Research

`alchemist_potions.yml` defines a competitive potion brewing quest.

| Field | Value |
| --- | --- |
| Quest id | `alchemist_potions` |
| Name | `<light_purple>Potion Research</light_purple>` |
| Material | `POTION` |
| Mode | `comp` |
| Duration | `1d` |
| Objective type | `BREWING_POTIONS` |
| Goal | `6000` |

## Objective behavior

`BREWING_POTIONS` counts completed potion results by potion effect and tier, for example `SPEED;1` or `STRENGTH;2`.
