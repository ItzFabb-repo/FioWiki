# Fishing Frenzy

`fishing_frenzy.yml` defines a competitive fishing quest.

| Field | Value |
| --- | --- |
| Quest id | `fishing_frenzy` |
| Name | `<aqua>Fishing Frenzy</aqua>` |
| Material | `FISHING_ROD` |
| Mode | `comp` |
| Duration | `1d` |
| Objective type | `FISHING` |
| Goal | `12000` |

## Objective behavior

`FISHING` counts matching caught fish or items, such as cod, salmon, tropical fish, or pufferfish.
