# Harvest Festival

`harvest_festival_farming.yml` defines a cooperative farming quest.

| Field | Value |
| --- | --- |
| Quest id | `harvest_festival_farming` |
| Name | `<yellow>Harvest Festival</yellow>` |
| Material | `WHEAT` |
| Mode | `coop` |
| Duration | `18h` |
| Objective type | `FARMING` |
| Goal | `40000` |

## Objective behavior

`FARMING` counts harvesting fully grown configured crops.
