# Forge Heat

`forge_smelting.yml` defines a cooperative smelting quest.

| Field | Value |
| --- | --- |
| Quest id | `forge_smelting` |
| Name | `<red>Forge Heat</red>` |
| Material | `FURNACE` |
| Mode | `coop` |
| Duration | `1d` |
| Objective type | `SMELTING` |
| Goal | `45000` |

## Objective behavior

`SMELTING` counts matching input materials processed through furnaces, such as ores, raw metals, or configured items.
