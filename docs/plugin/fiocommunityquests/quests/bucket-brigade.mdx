# Bucket Brigade

`bucket_brigade.yml` defines a cooperative bucket objective quest.

| Field | Value |
| --- | --- |
| Quest id | `bucket_brigade` |
| Name | `<blue>Bucket Brigade</blue>` |
| Material | `WATER_BUCKET` |
| Mode | `coop` |
| Duration | `12h` |
| Objective type | `BUCKET_EMPTY` |
| Goal | `8000` |

## Objective behavior

`BUCKET_EMPTY` counts players emptying matching filled buckets into the world, such as water, lava, or powder snow buckets.
