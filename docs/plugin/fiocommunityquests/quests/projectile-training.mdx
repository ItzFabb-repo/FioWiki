# Projectile Training

`projectile_training.yml` defines a competitive projectile launch quest.

| Field | Value |
| --- | --- |
| Quest id | `projectile_training` |
| Name | `<yellow>Projectile Training</yellow>` |
| Material | `BOW` |
| Mode | `comp` |
| Duration | `12h` |
| Objective type | `PROJECTILE_LAUNCH` |
| Goal | `20000` |

## Objective behavior

`PROJECTILE_LAUNCH` counts matching launched, thrown, or shot projectiles such as arrows, snowballs, tridents, or ender pearls.
