# Alchemist Ingredients

`alchemist_ingredients.yml` defines a cooperative brewing ingredient quest.

| Field | Value |
| --- | --- |
| Quest id | `alchemist_ingredients` |
| Name | `<dark_purple>Alchemist Ingredients</dark_purple>` |
| Material | `BREWING_STAND` |
| Mode | `coop` |
| Duration | `1d` |
| Objective type | `BREWING_INGREDIENTS` |
| Goal | `12000` |

## Objective behavior

`BREWING_INGREDIENTS` counts brewing progress from configured raw potion ingredients such as nether wart, magma cream, ghast tear, or gunpowder.
