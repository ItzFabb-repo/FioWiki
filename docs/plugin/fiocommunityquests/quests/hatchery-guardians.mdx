# Hatchery Guardians

`hatchery_guardians.yml` defines a cooperative hatching quest.

| Field | Value |
| --- | --- |
| Quest id | `hatchery_guardians` |
| Name | `<aqua>Hatchery Guardians</aqua>` |
| Material | `EGG` |
| Mode | `coop` |
| Duration | `1d` |
| Objective type | `HATCHING` |
| Goal | `3000` |

## Objective behavior

`HATCHING` counts matching egg hatch events, such as regular eggs, turtle eggs, or sniffer eggs when supported by the server version.
