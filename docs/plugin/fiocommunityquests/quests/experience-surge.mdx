# Experience Surge

`experience_surge.yml` defines a cooperative experience point quest.

| Field | Value |
| --- | --- |
| Quest id | `experience_surge` |
| Name | `<green>Experience Surge</green>` |
| Material | `EXPERIENCE_BOTTLE` |
| Mode | `coop` |
| Duration | `1d` |
| Objective type | `EXP_POINTS` |
| Goal | `250000` |

## Objective behavior

`EXP_POINTS` counts gained experience points. The required list can also define a numeric target.
