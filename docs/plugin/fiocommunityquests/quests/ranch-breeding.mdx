# Ranch Breeding

`ranch_breeding.yml` defines a cooperative breeding quest.

| Field | Value |
| --- | --- |
| Quest id | `ranch_breeding` |
| Name | `<gold>Ranch Breeding</gold>` |
| Material | `WHEAT` |
| Mode | `coop` |
| Duration | `1d` |
| Objective type | `ENTITY_BRED` |
| Goal | `10000` |

## Objective behavior

`ENTITY_BRED` counts breeding matching entities such as cows, sheep, pigs, chickens, or horses.
