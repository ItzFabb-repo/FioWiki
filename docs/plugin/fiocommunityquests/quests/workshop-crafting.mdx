# Workshop Rush

`workshop_crafting.yml` defines a cooperative crafting quest.

| Field | Value |
| --- | --- |
| Quest id | `workshop_crafting` |
| Name | `<yellow>Workshop Rush</yellow>` |
| Material | `CRAFTING_TABLE` |
| Mode | `coop` |
| Duration | `1d` |
| Objective type | `CRAFTING` |
| Goal | `60000` |

## Objective behavior

`CRAFTING` counts crafting matching item or material outputs.
