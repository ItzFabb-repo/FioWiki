# Menu: QuestContributions

`menu/QuestContributions.yml` controls per-quest contribution views.

## Purpose

This menu displays contribution information for a selected quest, usually from active quest menu items or admin open commands.

## Opening

```text
/fiocommunityquest admin open <player> QuestContributions <questId>
```

The source tab-completes active and loaded quest ids for the argument.

## Typical content

Contribution menus are designed around:

- selected quest name
- community progress
- required progress
- completion percentage
- player contribution points
- top contribution entries
- click navigation back to the main quest menu
