# Developer API

This page documents the API exposed by the current FioLevels source.

## Package names

Use the real source package names:

```java
import com.itzfabb.fiolevels.api.FioLevelsApi;
import com.itzfabb.fiolevels.api.FioLevelsApiProvider;
```

## Accessing the API

```java
FioLevelsApi api = FioLevelsApiProvider.get();
if (api != null) {
    int level = api.getLevel(player);
    api.addTaskProgress(player, "rules1", 1);
}
```

Use `null` checks because the provider can return `null` when FioLevels is not available yet.

## Progress API

```java
int getProgressPercent(OfflinePlayer player);
String getProgressBar(OfflinePlayer player);
long getRequiredProgress(int level);
boolean addTaskProgress(Player player, String taskId, int amount);
boolean completeTask(Player player, String taskId);
boolean addRuleProgress(Player player, String type, Material material, int amount);
boolean claimLevelReward(Player player, int level);
```

Use `addTaskProgress` when you know the configured requirement id, such as `rules0` or `rules1`. Use `addRuleProgress` when you want to add progress by task type and material.

## Example integration

```java
FioLevelsApi api = FioLevelsApiProvider.get();
if (api == null) {
    return;
}

int before = api.getLevel(player);
api.addRuleProgress(player, "CUSTOM", null, 1);
int after = api.getLevel(player);

if (after > before) {
    player.sendMessage("Level up!");
}
```

## plugin.yml advice for integrations

In your own plugin:

```yaml
softdepend:
  - FioLevels
```

Then resolve the provider lazily or during `onEnable()` after the server has loaded soft dependencies.
