# Placeholders

FioFishing registers the `fiofishing` PlaceholderAPI expansion when PlaceholderAPI is installed. Use these tokens in menus, scoreboards, chat formats, or other PlaceholderAPI-compatible plugins.

## Player and event state

| Placeholder | Result |
| --- | --- |
| `%fiofishing_isThere_event%` | Whether a fishing event is active. |
| `%fiofishing_toggle_lootable%` | Player's loot/catch message toggle state. |
| `%fiofishing_toggle_fishingrod%` | Player's fishing-rod message toggle state. |
| `%fiofishing_toggle_eventLeaderboards%` | Player's event leaderboard toggle state. |
| `%fiofishing_toggle_durabilityBreaks%` | Player's durability warning toggle state. |
| `%fiofishing_events_running_rawType%` | Active event's internal type. |
| `%fiofishing_events_running_formattedType%` | Active event type formatted for display. |
| `%fiofishing_events_running_formattedTime%` | Remaining time formatted using configured time units. |

## Event time

The following suffixes are available for both `rawTime_by` and `formatted_by`:

`Seconds`, `Minutes`, `Hours`, `Days`, `Weeks`, `Months`, and `Years`.

Examples: `%fiofishing_events_running_rawTime_bySeconds%`, `%fiofishing_events_running_formatted_byMinutes%`.

## Event competition entries

Replace `<place>` with the position number:

- `%fiofishing_eventCompetition_fish_<place>%` — fish name for that rank.
- `%fiofishing_eventCompetition_player_<place>%` — player name for that rank.
- `%fiofishing_eventCompetition_size_<place>%` — fish size for that rank.

## Global statistics

| Placeholder | Result |
| --- | --- |
| `%fiofishing_global_totalCatch%` | Total recorded catches. |
| `%fiofishing_global_totalWon%` | Total money earned from fishing. |
| `%fiofishing_global_totalEarned%` | Total fishing earnings statistic. |
| `%fiofishing_global_biggestSize_size%` | Size of the largest recorded fish. |
| `%fiofishing_global_biggestSize_date%` | Date of that record. |
| `%fiofishing_global_biggestSize_playerName%` | Player holding the size record. |

Run `/fiofishing admin placeholders` in game to inspect the expansion's current placeholder list.
