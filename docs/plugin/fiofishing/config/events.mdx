# Event dan jadwal

Semua file event berada di `plugins/FioFishing/Events/`. Satu file `.yml` untuk satu event. File `settings.yml` mengatur jadwal mingguan.

## ID dan jenis event

Tuliskan ID huruf kecil di `id`; nama file sebaiknya menggambarkan ID tersebut. Pilih salah satu jenis yang tersedia:

| ID event | Jenis yang diisi pada `type` | Kriteria |
| --- | --- | --- |
| `most_fish_caught` | `MOST_FISH_CAUGHT` | Jumlah ikan terbanyak. |
| `most_largest_fish_caught` | `MOST_LARGEST_FISH_CAUGHT` | Skor dari tangkapan ikan besar. |
| `most_smallest_fish_caught` | `MOST_SMALLEST_FISH_CAUGHT` | Skor dari tangkapan ikan kecil. |
| `largest_fish_caught` | `LARGEST_FISH_CAUGHT` | Ikan terbesar. |
| `smallest_fish_caught` | `SMALLEST_FISH_CAUGHT` | Ikan terkecil. |
| `most_rarity_fish_caught` | `MOST_RARITY_FISH_CAUGHT` | Jumlah ikan dari rarity tertentu. |
| `most_junk_caught` | `MOST_JUNK_CAUGHT` | Jumlah junk. |
| `most_bait_used` | `MOST_BAIT_USED` | Jumlah bait yang digunakan. |
| `most_specific_bait_used` | `MOST_SPECIFIC_BAIT_USED` | Penggunaan bait tertentu. |
| `fishing_spree` | `FISHING_SPREE` | Fishing spree; dapat mempercepat waktu bite. |

## Bentuk file event

```yaml
# ID ini harus cocok dengan ID di jadwal mingguan.
id: most_fish_caught

settings:
  # Aktifkan agar event dapat dimulai atau dijadwalkan.
  enabled: true
  # Jenis event dari tabel di atas.
  type: MOST_FISH_CAUGHT
  # Filter rarity dan fish/bait ID; [] tidak membatasi.
  list-rarities: []
  match-fish-ids: []
  # Kecepatan bite, 1 normal dan lebih besar lebih cepat.
  bite-speed-multiplier: 1.0
  soundsDuringEvent:
    # Sound Minecraft yang dimainkan selama event.
    sound: MUSIC_DISC_CHIRP
    # Tick antarulangan; -1 hanya dimainkan saat mulai.
    tickLoop: 3700
    volume: 1.0
    pitch: 1.0
    # Kategori suara Minecraft, contoh MASTER, MUSIC, RECORDS.
    category: MASTER
  requirements:
    player:
      # Syarat jumlah pemain online.
      enable: true
      value: 5
    region:
      inPlayer:
        # Membutuhkan WorldGuard dan region yang ditulis di bawah.
        enable: false
        region:
          - fishing_dock
        # Jumlah minimum pemain di region.
        value: 5

event:
  whenStarted:
    # Jalankan aksi ketika event dimulai.
    enabled: true
    commands:
      - '[MESSAGE] <green>Event {eventName} dimulai!</green>'
  whenStopped:
    enabled: false
    commands: []

bossbar:
  # Warna: BLUE, GREEN, PINK, PURPLE, RED, WHITE, YELLOW.
  colour: BLUE
  # %time% adalah sisa waktu; {eventName} adalah nama event.
  message: '<aqua>Kontes Memancing</aqua>: <white>%time%</white>'

rewards:
  participate:
    # Hadiah untuk semua pemain yang mengikuti event.
    enable: false
    commands:
      - '[MONEY] 100'
  tier:
    commands:
      # Hadiah untuk ranking 1, 2, 3, dan peringkat lainnya (*).
      '1': ['[EXP_POINTS] 10']
      '2': ['[EXP_POINTS] 5']
      '*': []
```

## Opsi event

- `list-rarities` berisi ID rarity seperti `common`, `rare`, atau `'*'`. Berlaku untuk event yang membatasi rarity.
- `match-fish-ids` dapat diisi ID ikan atau bait sesuai tipe event; `'*'` berarti semua. Gunakan ID yang sama dengan file ikan/bait.
- Key `sound` di dalam `soundsDuringEvent` adalah nama sound Minecraft; `tickLoop: -1` berarti sekali ketika mulai, selain itu angka tick sebagai interval. Volume/pitch berupa angka. Kategori memakai nama SoundCategory, misalnya `MASTER`, `MUSIC`, `RECORDS`, `PLAYERS`, `AMBIENT`.
- Syarat pemain memakai jumlah minimum. Syarat region memerlukan WorldGuard, daftar nama region, dan jumlah pemain minimum.
- Bossbar menerima warna `BLUE`, `GREEN`, `PINK`, `PURPLE`, `RED`, `WHITE`, atau `YELLOW`.
- Reward tier menggunakan key ranking `'1'`, `'2'`, dan seterusnya; `'*'` adalah fallback untuk ranking tanpa key khusus.

## Jadwal mingguan

Edit `Events/settings.yml`. Setiap hari mempunyai `enable` dan `list-events`. Waktu menggunakan zona waktu lokal server.

```yaml
schedule:
  monday:
    # Matikan satu hari penuh dengan false.
    enable: true
    list-events:
      # Bentuk dengan waktu: id_event;HH:mm-HH:mm
      - 'most_fish_caught;18:00-19:00'
      # Tanpa rentang berarti sepanjang hari tersebut.
      - fishing_spree
  tuesday:
    enable: false
    list-events: []
```

Nama hari yang diterima: `monday`, `tuesday`, `wednesday`, `thursday`, `friday`, `saturday`, `sunday`. ID event pada daftar harus sama dengan nilai `id` di file event.

## Format aksi

```yaml
commands:
  - '[CONSOLE] say Event selesai'
  - '[MESSAGE] <green>Selamat!</green>'
  - '[SOUND] BLOCK_NOTE_BLOCK_PLING 1 2'
  - '[TITLE] <gold>Juara!</gold>'
  - '[SUBTITLE] Kamu mendapat hadiah'
  - '[MONEY] 100'
  - '[EXP_POINTS] 10'
  - '[EXP_LEVEL] 1'
  - '[ITEM] DIAMOND 1'
```

`[MONEY]` memakai perintah `eco give` dan perlu plugin ekonomi. `[ITEM]` memberi material Minecraft sederhana dan jumlah opsional. Perintah `[CONSOLE]` dijalankan sebagai console; aksi pemain diberikan kepada penerima reward. Teks mendukung MiniMessage dan placeholder event seperti `{eventName}`.
