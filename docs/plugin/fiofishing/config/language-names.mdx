# Language and Display Names

## Change the message language

The language setting is under `settings` in `config.yml`:

```yaml
settings:
  language: id
```

Built-in values are `en`, `id`, `jp`, and `ch`. The plugin loads `plugins/FioFishing/Lang/messages_<code>.yml`. For example, `language: id` uses `Lang/messages_id.yml`.

To change message text, edit the values in the language file and keep the keys on the left unchanged. Preserve placeholders such as `{player}`, `{fish}`, `{length}`, and `{eventName}` when the message uses them. Messages support MiniMessage (for example, `<green>Text</green>`); some legacy values may use `&` color codes.

You can add a language code by creating `Lang/messages_<code>.yml` from the most complete language file, then setting the same code under `settings.language`. Missing keys use that language's default text or fall back to English.

## Material and biome aliases

Alias files are located at:

- `plugins/FioFishing/CustomNaming/material.json`
- `plugins/FioFishing/CustomNaming/biome.json`

Both files map IDs to display names. Built-in materials and biomes are already registered. Add entries for resource-pack items or datapack biomes:

`material.json`:

```json
{
  "minecraft:cod": "River Fish",
  "mypack:river_carp": "River Carp"
}
```

`biome.json`:

```json
{
  "my_datapack:crystal_lake": "Crystal Lake"
}
```

Use valid JSON: double quotes, commas between entries, and no comma after the final entry. The plugin matches IDs without case sensitivity. For a custom biome, use the same namespaced ID in the fish file under `conditions.biome`. If a fish uses `displayName: FOLLOW_MATERIAL_ALIAS`, its material name is read from `material.json`.

## MiniMessage colors

Item names, lore, messages, titles, and bossbars can support MiniMessage. Example:

```yaml
displayName: '<#45D6B5>Green Fish</#45D6B5>'
lore:
  - '<gray>A fish from a special lake.</gray>'
  - '<yellow>Price: {worth}</yellow>'
```

Make sure every tag is properly opened and closed. Plain text also works when you do not need colors.
