# Bahasa dan nama tampilan

## Mengubah bahasa pesan

Pengaturan bahasa berada di dalam bagian `settings` pada `config.yml`:

```yaml
settings:
  language: id
```

Nilai bawaan: `en`, `id`, `jp`, dan `ch`. Plugin memilih file `plugins/FioFishing/Lang/messages_<kode>.yml`. Contohnya `language: id` memakai `Lang/messages_id.yml`.

Untuk mengubah teks, edit nilai pesan pada file bahasa dan pertahankan key di sisi kiri. Placeholder seperti `{player}`, `{fish}`, `{length}`, `{eventName}` harus tetap ada bila diperlukan oleh pesan tersebut. Pesan menggunakan MiniMessage (contoh `<green>Teks</green>`) dan beberapa nilai lama dapat memakai format warna `&`.

Anda dapat menambahkan kode bahasa sendiri dengan membuat `Lang/messages_<kode>.yml` berdasarkan file yang paling lengkap, lalu mengatur `language` di bawah `settings` ke kode yang sama. Key yang belum tersedia di file pilihan memakai teks default bahasa itu atau fallback Inggris.

## Alias material dan biome

File alias berada di:

- `plugins/FioFishing/CustomNaming/material.json`
- `plugins/FioFishing/CustomNaming/biome.json`

Keduanya berbentuk pasangan ID ke nama tampilan. Material/biome bawaan sudah terdaftar. Tambahkan baris baru untuk resource pack atau biome datapack:

`material.json`:

```json
{
  "minecraft:cod": "Ikan Sungai",
  "mypack:river_carp": "Ikan Mas Sungai"
}
```

`biome.json`:

```json
{
  "my_datapack:crystal_lake": "Danau Kristal"
}
```

Format yang benar adalah JSON: gunakan tanda kutip ganda, koma di antara entri, dan jangan menaruh koma setelah entri terakhir. Plugin mencocokkan ID tanpa membedakan huruf besar/kecil. Untuk biome custom, gunakan ID namespaced yang sama pada bagian `conditions`, key `biome` di file ikan. Jika nama ikan menggunakan `displayName: FOLLOW_MATERIAL_ALIAS`, nama materialnya diambil dari `material.json`.

## Format warna MiniMessage

Nama item, lore, pesan, title, dan bossbar dapat mendukung MiniMessage. Contoh:

```yaml
displayName: '<#45D6B5>Ikan Hijau</#45D6B5>'
lore:
  - '<gray>Ikan dari danau khusus.</gray>'
  - '<yellow>Harga: {worth}</yellow>'
```

Pastikan tag dibuka dan ditutup dengan benar. Bila pesan tidak perlu warna, teks biasa juga bisa dipakai.
