# Create Custom Baits

Definisi bait ada di `plugins/FioFishing/Loots/Baits/`. Satu file `.yml` untuk satu jenis bait. Salin contoh, ubah ID/nilai, lalu simpan dan jalankan `/fiofishing admin reload`.

## Struktur dan pengaturan bait

```yaml
baits:
  settings:
    # ID wajib dan harus unik. Dipakai oleh rod, menu, dan perintah give.
    id: worm
    # Menyalakan atau mematikan bait.
    enable: true
    # Kembalikan bait bila kail ditarik tanpa tangkapan.
    refund_if_empty_reel: true
    # Apakah bait habis ketika lemparan dibatalkan.
    consume_if_cancelled_cast: false
    # Sembunyikan pesan penggunaan bait.
    silent: false
    keep:
      # Aktifkan peluang agar bait tetap ada setelah digunakan.
      enable: false
      # Peluang tetap ada, misalnya '50' atau '50%'.
      chance: '50'
    # Maksimum bait yang dapat dipasang pada satu rod.
    max-bait-stack: 4
    # Maksimum item bait per stack inventori (batas atas 64).
    max-item-stack: 12
    modifier:
      multiplier:
        # Bonus persen untuk rarity rare, epic, legendary, mythic.
        rarity: 15
        # Nilai umum contoh; target ikan/rareness diatur pada bagian fish di bawah.
        fish: 0
        # Pengali kecepatan gigitan: 1 normal, 1.2 lebih cepat.
        bite-speed: 1.15
        # Pengali XP dan ukuran hasil.
        xp: 1.25
        size: 1.15
    requirements:
      # Permission wajib; none berarti tidak ada permission khusus.
      permission: none
      # ID rod yang menerima bait ini; [] berarti rod apa saja.
      allowed-rods-id: []
      worlds:
        # Jika diisi, hanya world ini yang mengizinkan bait.
        whitelist: []
        # World tempat bait tidak dapat digunakan.
        blacklist: []
      regions:
        # Region WorldGuard yang mengizinkan bait.
        whitelist: []
        # Region WorldGuard yang melarang bait.
        blacklist: []
    fish:
      # ID rarity: * menerapkan aturan ke semua ikan pada rarity tersebut.
      rare:
        '*': '+15'
      common:
        # ID ikan tertentu dapat diberi aturan sendiri.
        river_carp: '/2'
    price:
      # Bisa dijual kembali dari menu sell.
      should-this-bait-sell-able-again: true
      # Tersedia di menu shop.
      should-this-bait-be-purchaseable: true
      # Sembunyikan di shop saat tidak dapat dibeli.
      should-this-bait-hidden-if-not-purchaseable: false
      # Persen harga yang dikembalikan saat dijual.
      refund-if-sell: '25%'
      # Harga bait dalam mata uang ekonomi server.
      bait-sell-price: '100.0'

item:
  # Material dasar item Minecraft.
  material: PAPER
  custom:
    # VANILLA, ITEMSADDER, ORAXEN, NEXO.
    type: VANILLA
    # CustomModelData ketika menggunakan model vanilla.
    modelData: 1010
    # ID item dari ItemsAdder/Oraxen/Nexo jika memakai plugin tersebut.
    # custom: mypack:worm_bait
  # Nama dan lore menerima teks MiniMessage.
  display_name: '<green>Umpan Cacing</green>'
  lore:
    - '<gray>Umpan untuk ikan sungai.</gray>'
    - '<yellow>Bonus rarity: 15%</yellow>'
  behavior:
    # Tampilkan glint enchant.
    glow: true
    # Aturan interaksi item. true memblokir, false membolehkan.
    block:
      HOPPER: false
      CHEST: false
      CRAFTER: true
    # Aturan lingkungan. true mencegah aksi yang disebut.
    environment:
      DESTROYED_BY_CACTUS: true
      DESTROYED_BY_LAVA: true
      IS_EDIBLE: false
      PLACE: false
      DROP: false
```

## Arti modifier dan nilai yang dapat diisi

- `rarity` berupa bonus persen. Contohnya `15` memberi bonus 15% pada kategori rarity langka (`rare`, `epic`, `legendary`, `mythic`); `0` berarti tanpa bonus.
- `bite-speed`, `xp`, dan `size` adalah pengali angka. `1.0` netral, `1.2` meningkatkan 20%, `0.8` menurunkan nilai sekitar 20%.
- Bagian `fish` memakai nama rarity dan fish ID. Nilai harus berupa string yang dikutip: `'+15'` menambah bobot 15%, `'/2'` membagi bobot menjadi setengah, sedangkan `'2'` berarti pengali langsung 2.
- Persentase `chance` di bagian `keep` dan `refund-if-sell` dapat ditulis sebagai teks `'50%'` atau `'50'`.
- Stack item berada pada rentang 1 sampai 64. Bait per rod minimal 1.

## Cara memasang bait dan mengatur syarat

Untuk memasang bait, letakkan bait dan rod di inventori lalu gunakan gesture yang dikonfigurasi pada bagian `settings` → `interaction` di halaman [Pengaturan umum](./config.mdx). Default-nya `LEFT_CLICK_DRAG`; melepas/mengelola bait memakai `SHIFT_Q`.

`allowed-rods-id` di bawah `requirements` harus memuat ID rod dari file rod, bukan nama tampilan. Daftar dunia/region kosong berarti tidak membatasi. WorldGuard diperlukan bila menggunakan filter region.

Contoh syarat:

```yaml
requirements:
  permission: fiofishing.bait.worm
  allowed-rods-id:
    - wooden_rod
    - master_rod
  worlds:
    whitelist: [fishing_world]
    blacklist: []
  regions:
    whitelist: [fishing_dock]
    blacklist: [safe_zone]
```

Item custom mendukung `VANILLA`, `ITEMSADDER`, `ORAXEN`, atau `NEXO`. Untuk tiga opsi plugin, isi ID di `custom` dan pastikan pluginnya terpasang. Nama item/lore dapat memakai tag MiniMessage seperti `<aqua>` dan warna hex.

Shop/sell bait menggunakan konfigurasi harga di atas, Vault, dan plugin ekonomi. `should-this-bait-be-purchaseable` mengontrol pembelian; `should-this-bait-sell-able-again` mengontrol penjualan kembali.
