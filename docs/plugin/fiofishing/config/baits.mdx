# Create Custom Baits

Bait definitions are stored in `plugins/FioFishing/Loots/Baits/`, with one `.yml` file per bait type. Copy an example, change its ID and values, save the file, and run `/fiofishing admin reload`.

## Bait structure and settings

```yaml
baits:
  settings:
    # Required unique ID used by rods, menus, and the give command.
    id: worm
    # Enable or disable this bait.
    enable: true
    # Refund the bait when the hook is reeled in without a catch.
    refund_if_empty_reel: true
    # Whether to consume the bait when a cast is cancelled.
    consume_if_cancelled_cast: false
    # Hide bait usage messages.
    silent: false
    keep:
      # Enable a chance for the bait to remain after use.
      enable: false
      # Chance to keep the bait, for example '50' or '50%'.
      chance: '50'
    # Maximum number of baits that can be attached to one rod.
    max-bait-stack: 4
    # Maximum bait items per inventory stack (up to 64).
    max-item-stack: 12
    modifier:
      multiplier:
        # Percentage bonus for rare, epic, legendary, and mythic rarities.
        rarity: 15
        # General example value; fish-specific targets are set under fish below.
        fish: 0
        # Bite-speed multiplier: 1 is normal, 1.2 is faster.
        bite-speed: 1.15
        # XP and catch-size multipliers.
        xp: 1.25
        size: 1.15
    requirements:
      # Required permission; none means no special permission is required.
      permission: none
      # Rod IDs that accept this bait; [] allows any rod.
      allowed-rods-id: []
      worlds:
        # If set, this whitelist limits where the bait can be used.
        whitelist: []
        # Worlds where this bait cannot be used.
        blacklist: []
      regions:
        # WorldGuard regions where this bait is allowed.
        whitelist: []
        # WorldGuard regions where this bait is blocked.
        blacklist: []
    fish:
      # Rarity ID; '*' applies the rule to every fish in that rarity.
      rare:
        '*': '+15'
      common:
        # A specific fish ID can have its own rule.
        river_carp: '/2'
    price:
      # Allow this bait to be resold through the sell menu.
      should-this-bait-sell-able-again: true
      # Make this bait available in the shop.
      should-this-bait-be-purchaseable: true
      # Hide this bait in the shop when it cannot be purchased.
      should-this-bait-hidden-if-not-purchaseable: false
      # Percentage of the price refunded when the bait is sold.
      refund-if-sell: '25%'
      # Bait price in the server economy currency.
      bait-sell-price: '100.0'

item:
  # Base Minecraft item material.
  material: PAPER
  custom:
    # VANILLA, ITEMSADDER, ORAXEN, or NEXO.
    type: VANILLA
    # CustomModelData for a vanilla model.
    modelData: 1010
    # ItemsAdder/Oraxen/Nexo item ID when using one of those plugins.
    # custom: mypack:worm_bait
  # Name and lore support MiniMessage text.
  display_name: '<green>Worm Bait</green>'
  lore:
    - '<gray>Bait for river fish.</gray>'
    - '<yellow>Rarity bonus: 15%</yellow>'
  behavior:
    # Show an enchantment glint.
    glow: true
    # Item interaction rules. true blocks the action; false allows it.
    block:
      HOPPER: false
      CHEST: false
      CRAFTER: true
    # Environment rules. true prevents the listed action.
    environment:
      DESTROYED_BY_CACTUS: true
      DESTROYED_BY_LAVA: true
      IS_EDIBLE: false
      PLACE: false
      DROP: false
```

## Modifier meanings and accepted values

- `rarity` is a percentage bonus. For example, `15` adds 15% to rare categories (`rare`, `epic`, `legendary`, `mythic`); `0` gives no bonus.
- `bite-speed`, `xp`, and `size` are numeric multipliers. `1.0` is neutral, `1.2` increases the value by 20%, and `0.8` lowers it by about 20%.
- The `fish` section uses rarity names and fish IDs. Values must be quoted strings: `'+15'` adds 15% to the weight, `'/2'` halves it, and `'2'` applies a direct multiplier of 2.
- The `chance` under `keep` and `refund-if-sell` can be written as `'50%'` or `'50'`.
- Item stack sizes range from 1 to 64. The bait stack per rod must be at least 1.

## Attaching bait and setting requirements

To attach bait, place the bait and rod in your inventory and use the gesture configured under `settings` → `interaction` in [General settings](./config.mdx). The default is `LEFT_CLICK_DRAG`; use `SHIFT_Q` to remove or manage bait.

`allowed-rods-id` under `requirements` must contain rod IDs from the rod files, not display names. Empty world or region lists do not restrict usage. WorldGuard is required for region filters.

Example requirements:

```yaml
requirements:
  permission: fiofishing.bait.worm
  allowed-rods-id:
    - wooden_rod
    - master_rod
  worlds:
    whitelist: [fishing_world]
    blacklist: []
  regions:
    whitelist: [fishing_dock]
    blacklist: [safe_zone]
```

Custom items support `VANILLA`, `ITEMSADDER`, `ORAXEN`, or `NEXO`. For the external plugins, set the item ID under `custom` and make sure the plugin is installed. Item names and lore can use MiniMessage tags such as `<aqua>` and hex colors.

The bait shop and sell menu use the prices above, Vault, and an economy plugin. `should-this-bait-be-purchaseable` controls purchases; `should-this-bait-sell-able-again` controls resale.
