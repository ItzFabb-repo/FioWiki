# Menus

Menu YAML files are loaded recursively from `plugins/FioFishing/Menu/`. The path is significant: a menu at `Menu/Shop/Baits.yml` can be opened by its relative menu path. The bundled files cover bait display, selling, shop, admin give screens and the fish journey.

## Menu layout

A menu has a title and either `rows` (1–6) or a `size` (9–54, in multiples of 9). Item entries define a material, slot or slot list/range, name, lore, flags and actions.

```yaml
title: '<dark_green>Fishing Shop</dark_green>'
rows: 6
items:
  back:
    material: ARROW
    slot: 49
    name: '<yellow>Back</yellow>'
    actions:
      left:
        - '[BACK]'
```

Slots use zero-based inventory slots. Lists can include ranges, for example `'1,3-5'` or `'0-44'`. Match the key structure in a bundled menu when editing dynamic menus so generated items and placeholders continue to work.

## Click actions

Actions are listed under click names such as `left`, `shift_left`, `right`, `shift_right`, `q`, `shift_any` or `any`. Supported action prefixes include:

| Action | Effect |
| --- | --- |
| `[NONE]` | No action. |
| `[CLOSE]` | Close the inventory. |
| `[BACK]` | Return to the previous menu. |
| `[OPENMENU] <path>` | Open a menu by its path under `Menu/`. |
| `[PLAYER] <command>` | Run a command as the clicking player. |
| `[CONSOLE] <command>` | Run a command as console. |
| `[TITLE]`, `[SUBTITLE]`, `[ACTIONBAR]`, `[MESSAGE]` | Send text to the player. |
| `[SOUND] <sound> [volume] [pitch]` | Play a sound. |

Admins can inspect/open menu files with `/fiofishing admin menu forceopen <player> <Menu/path.yml>`. Use forward slashes in the menu path.
