# GUI Menus

Menu files are stored in `plugins/FioFishing/Menu/`, and subfolders are loaded as well. Edit `.yml` files to change the size, title, buttons, lore, and click actions. Keep the keys used by dynamic menus such as the shop, sell, journal, and admin menus.

## Built-in menus

| File | Purpose |
| --- | --- |
| `Menu/baits.yml` | Manage bait attached to rods. |
| `Menu/Sell.yml` | Place items that you want to sell. |
| `Menu/Shop/Menu.yml` | Main shop page. |
| `Menu/Shop/Baits.yml` | List of bait for sale. |
| `Menu/Shop/FishingRods.yml` | List of rods for sale. |
| `Menu/Journey/menu.yml` | Fish journal page. |
| `Menu/Journey/Rarity/<rarity>.yml` | Fish list for a rarity. |
| `Menu/Admin/Gives/...` | Admin menus for giving fish, bait, and rods. |

## Menu and button structure

```yaml
# Menu title text; supports MiniMessage.
title: '<dark_green>Fishing Shop</dark_green>'
# Set 1 to 6 rows. Alternatively, set size to a multiple of 9.
rows: 6
# size: 54

items:
  back:
    # Minecraft icon material.
    material: ARROW
    # Slots start at 0 in the top-left corner.
    slot: 49
    # Use multiple slots or ranges instead of one slot.
    # slots: ['45-53']
    name: '<yellow>Back</yellow>'
    lore:
      - '<gray>Return to the previous page</gray>'
    # flags hide parts of the tooltip; hide_tooltip hides the entire tooltip.
    flags: []
    hide_tooltip: false
    actions:
      # Click names: left, shift_left, right, shift_right, q, shift_any, any.
      left:
        - '[BACK]'
      any:
        - '[NONE]'
```

- `rows` accepts `1`–`6`. Alternatively, `size` accepts `9`, `18`, `27`, `36`, `45`, or `54`.
- `slot` is a single slot; `slots` is a list of numbers, ranges, or both, for example `['1,3-5']`. Ranges include both endpoints.
- `material` is a Minecraft material name. An invalid material prevents the button from appearing.
- `name` and `lore` support MiniMessage. `flags` accepts Minecraft item flags such as `HIDE_ATTRIBUTES` or `HIDE_ENCHANTMENTS`.
- `actions` contains a list of actions for each click type. Use `any` when the same action should run for every click type.

## Available button actions

```yaml
actions:
  left:
    - '[OPENMENU] Shop/Baits.yml'
  right:
    - '[MESSAGE] <green>Opening the bait shop</green>'
  shift_left:
    - '[PLAYER] fiofishing shop'
  any:
    - '[NONE]'
```

| Action prefix | Purpose |
| --- | --- |
| `[NONE]` | Do nothing. |
| `[CLOSE]` | Close the inventory. |
| `[BACK]` | Return to the previous menu. |
| `[OPENMENU] <path>` | Open a menu relative to the Menu folder; the `.yml` extension is optional. |
| `[PLAYER] <command>` | Run a command as the player. |
| `[CONSOLE] <command>` | Run a command as the console. |
| `[TITLE] <text>` | Show a title. |
| `[SUBTITLE] <text>` | Show a subtitle. |
| `[ACTIONBAR] <text>` | Show an action bar. |
| `[MESSAGE] <text>` | Send a chat message. |
| `[SOUND] <SOUND> <volume> <pitch> [category]` | Play a sound; the optional category defaults to `MASTER`. |

## Dynamic menus

Menus such as the sell menu can have a `content` section that defines the slots where items are placed:

```yaml
content:
  slots:
    - '0-44'
```

Do not remove `slots` under `content`, navigation items, sell buttons, or special item IDs from built-in menus if you want their dynamic behavior to keep working. Admin menu paths are relative to the Menu folder, for example `Menu/Shop/Baits.yml` in `/fiofishing admin menu forceopen <player> <path>`.
