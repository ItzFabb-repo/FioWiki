# Menu GUI

File menu berada di `plugins/FioFishing/Menu/`; subfolder ikut dibaca. Edit file `.yml` untuk mengubah ukuran, judul, tombol, lore, dan aksi klik. Pertahankan key yang dipakai menu dinamis seperti shop, sell, journal, dan menu admin.

## Menu bawaan

| File | Fungsi |
| --- | --- |
| `Menu/baits.yml` | Mengelola bait pada rod. |
| `Menu/Sell.yml` | Tempat menaruh item yang hendak dijual. |
| `Menu/Shop/Menu.yml` | Halaman utama shop. |
| `Menu/Shop/Baits.yml` | Daftar bait yang dijual. |
| `Menu/Shop/FishingRods.yml` | Daftar rod yang dijual. |
| `Menu/Journey/menu.yml` | Halaman jurnal/perjalanan ikan. |
| `Menu/Journey/Rarity/<rarity>.yml` | Daftar ikan berdasarkan rarity. |
| `Menu/Admin/Gives/...` | Menu admin untuk memberikan ikan, bait, dan rod. |

## Struktur menu dan tombol

```yaml
# Teks judul menu; mendukung MiniMessage.
title: '<dark_green>Fishing Shop</dark_green>'
# Isi 1 sampai 6 baris. Alternatifnya gunakan size kelipatan 9.
rows: 6
# size: 54

items:
  back:
    # Material ikon Minecraft.
    material: ARROW
    # Slot dimulai dari 0 pada kiri atas.
    slot: 49
    # Bisa memakai slot jamak/rentang alih-alih satu slot.
    # slots: ['45-53']
    name: '<yellow>Kembali</yellow>'
    lore:
      - '<gray>Kembali ke halaman sebelumnya</gray>'
    # flags menyembunyikan bagian tooltip; hide_tooltip menyembunyikan tooltip.
    flags: []
    hide_tooltip: false
    actions:
      # Nama klik: left, shift_left, right, shift_right, q, shift_any, any.
      left:
        - '[BACK]'
      any:
        - '[NONE]'
```

- `rows` menerima `1`–`6`. Alternatif `size` menerima `9`, `18`, `27`, `36`, `45`, atau `54`.
- `slot` adalah satu slot; `slots` adalah daftar angka, rentang, atau gabungannya, misalnya `['1,3-5']`. Rentang termasuk angka awal dan akhir.
- `material` adalah nama material Minecraft. Jika material salah, tombol tidak akan tampil.
- `name` dan `lore` mendukung MiniMessage. `flags` menerima daftar item flag Minecraft seperti `HIDE_ATTRIBUTES` atau `HIDE_ENCHANTMENTS`.
- Bagian `actions` berisi daftar aksi per jenis klik. Gunakan `any` bila aksi sama untuk semua jenis klik.

## Aksi tombol yang tersedia

```yaml
actions:
  left:
    - '[OPENMENU] Shop/Baits.yml'
  right:
    - '[MESSAGE] <green>Membuka shop bait</green>'
  shift_left:
    - '[PLAYER] fiofishing shop'
  any:
    - '[NONE]'
```

| Awalan aksi | Fungsi |
| --- | --- |
| `[NONE]` | Tidak melakukan apa-apa. |
| `[CLOSE]` | Menutup inventory. |
| `[BACK]` | Kembali ke menu sebelumnya. |
| `[OPENMENU] <path>` | Membuka menu relatif ke folder Menu; ekstensi `.yml` boleh ada atau tidak. |
| `[PLAYER] <perintah>` | Menjalankan perintah sebagai pemain. |
| `[CONSOLE] <perintah>` | Menjalankan perintah sebagai console. |
| `[TITLE] <teks>` | Menampilkan title. |
| `[SUBTITLE] <teks>` | Menampilkan subtitle. |
| `[ACTIONBAR] <teks>` | Menampilkan action bar. |
| `[MESSAGE] <teks>` | Mengirim pesan chat. |
| `[SOUND] <SOUND> <volume> <pitch> [kategori]` | Memainkan sound; kategori opsional dan default `MASTER`. |

## Menu dinamis

Menu seperti sell dapat memiliki section `content` yang menentukan slot tempat item diletakkan:

```yaml
content:
  slots:
    - '0-44'
```

Jangan menghapus daftar `slots` di dalam bagian `content`, item navigasi, tombol jual, atau ID item khusus dari menu bawaan jika ingin fungsi dinamis tetap bekerja. Path menu untuk admin memakai path relatif seperti `Menu/Shop/Baits.yml` pada `/fiofishing admin menu forceopen <pemain> <path>`.
