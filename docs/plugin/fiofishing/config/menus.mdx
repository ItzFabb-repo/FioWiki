# Menu GUI

Semua menu dibaca dari `plugins/FioFishing/Menu/`, termasuk subfoldernya. File `.yml` bisa berisi tampilan menu, tombol item, dan aksi ketika tombol diklik. Jangan mengganti nama menu bawaan tanpa memperbarui rujukan path menu lainnya.

## Menu bawaan

| Lokasi | Fungsi |
| --- | --- |
| `Menu/baits.yml` | Inventori pengelolaan bait pada rod. |
| `Menu/Sell.yml` | Area untuk menaruh item yang hendak dijual. |
| `Menu/Shop/Menu.yml` | Halaman utama shop. |
| `Menu/Shop/Baits.yml` | Daftar umpan shop. |
| `Menu/Shop/FishingRods.yml` | Daftar rod shop. |
| `Menu/Journey/menu.yml` | Halaman jurnal ikan. |
| `Menu/Journey/Rarity/<rarity>.yml` | Halaman ikan per rarity. |
| `Menu/Admin/Gives/...` | Menu untuk memberikan ikan, bait, atau rod. |

Salin file terdekat sebelum membuat file menu baru agar ID item dinamis dan tombol bawaan tetap mengikuti format yang benar.

## Key menu

```yaml
title: '<dark_green>Fishing Shop</dark_green>'
rows: 6
items:
  back:
    material: ARROW
    slot: 49
    name: '<yellow>Kembali</yellow>'
    lore:
      - '<gray>Kembali ke halaman sebelumnya</gray>'
    actions:
      left:
        - '[BACK]'
```

| Key | Opsi/nilai | Fungsi |
| --- | --- | --- |
| `title` | Teks MiniMessage | Judul inventori. |
| `rows` | `1`–`6` | Jumlah baris, 9 slot setiap baris. |
| `size` | `9`, `18`, `27`, `36`, `45`, `54` | Alternatif ukuran langsung dalam slot; kelipatan 9. Jika `rows` valid, `rows` digunakan. |
| `items` | Peta nama tombol/item | Setiap key anak menjadi satu item/menu control. |
| `items.<nama>.material` | Nama material Minecraft | Item ikon. Material tidak valid membuat item tidak tampil. |
| `slot` | Bilangan bulat 0-based | Satu slot item; slot `0` adalah pojok kiri atas. |
| `slots` | Daftar rentang atau daftar angka string | Banyak slot, contoh `['0-44']` atau `['1,3-5']`. |
| `name` | Teks MiniMessage | Nama ikon. |
| `lore` | Daftar teks | Deskripsi ikon. |
| `flags` | Daftar ItemFlag | Menyembunyikan bagian tooltip item. Misalnya `HIDE_ATTRIBUTES`, `HIDE_ENCHANTMENTS`. |
| `hide_tooltip` | Boolean | Menyembunyikan seluruh tooltip item. |
| `actions` | Peta click ke daftar aksi | Aksi saat pemain mengklik item. |

Rentang slot bersifat inklusif. Contoh `'45-53'` mencakup 9 slot. Gunakan slot 0 sampai ukuran menu dikurangi 1.

## Opsi klik

Tuliskan aksi di bawah nama klik berikut: `left`, `shift_left`, `right`, `shift_right`, `q`, `shift_any`, atau `any`.

| Aksi | Efek |
| --- | --- |
| `[NONE]` | Tidak melakukan apa-apa. Gunakan untuk dekorasi. |
| `[CLOSE]` | Menutup menu. |
| `[BACK]` | Membuka menu sebelumnya. |
| `[OPENMENU] Shop/Baits` | Membuka file relatif terhadap folder `Menu/`; ekstensi `.yml` boleh dicantumkan atau dihilangkan. |
| `[PLAYER] <perintah>` | Menjalankan perintah sebagai pemain. |
| `[CONSOLE] <perintah>` | Menjalankan perintah sebagai console. |
| `[TITLE] <teks>` | Menampilkan title. |
| `[SUBTITLE] <teks>` | Menampilkan subtitle. |
| `[ACTIONBAR] <teks>` | Mengirim action bar. |
| `[MESSAGE] <teks>` | Mengirim pesan chat. |
| `[SOUND] <SOUND> <volume> <pitch> [kategori]` | Memainkan sound; kategori opsional, default `MASTER`. |

Contoh tombol yang membuka sub-menu:

```yaml
items:
  bait-shop:
    material: WHEAT
    slot: 20
    name: '<green>Beli Umpan</green>'
    lore:
      - '<gray>Lihat semua bait</gray>'
    actions:
      left:
        - '[OPENMENU] Shop/Baits.yml'
      any:
        - '[NONE]'
```

## Pengaturan menu dinamis

Menu shop, sell, journal, dan admin dapat diisi oleh FioFishing menggunakan item atau slot yang didefinisikan plugin. Jangan menghapus section yang dipakai halaman dinamis, seperti `content.slots`, daftar item placeholder, atau aksi tombol navigasi. Untuk memberi menu kepada admin secara paksa, perintahnya `/fiofishing admin menu forceopen <pemain> <Menu/path.yml>`.
