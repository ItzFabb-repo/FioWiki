# Create Custom Fishs

Create and edit fish in `plugins/FioFishing/Loots/Fish/*.yml`. Bundled files are grouped by rarity, such as `common.yml`, `rare.yml`, and `mythic.yml`. Copy the closest example, then update its values and comments as needed.

## Fish file structure

```yaml
rarity:
  # Rarity ID used by fish, rod filters, and bait modifiers.
  id: common
  # Order of this rarity in menus; lower numbers appear first.
  weight: 1
  # Multiplier for all fish weights in this file; 1 is normal, 0 disables their chance.
  catch-weight: 1
  # Sell-price multiplier; 1 is the normal price.
  worth-multi: 1.0
  fih-animations:
    # Animated entity shown when a fish of this rarity bites.
    entity: TROPICAL_FISH
  settings:
    broadcast:
      # Enable announcements for catches of this rarity.
      enable: false
      # When true, announce only if the angler is holding a rod.
      if-only-holdingRods: true
      # List of actions; see the examples below for the format.
      message:
        - '[MESSAGE] <gray>{player} caught {fish}</gray>'
        - '[SOUND] BLOCK_BUBBLE_COLUMN_BUBBLE_POP 1 1 master'
  default_settings:
    size:
      # Default fish-size range in centimeters.
      min: 1
      max: 20
    # Record the catch in angler statistics.
    fisherman: false
    # Record the catch in the journal.
    journal: true
    # Base price before worth-multi is applied.
    worth: 0.50
    conditions:
      # Allowed biomes; [] means every biome.
      biome: []
      # Time: DAY, NIGHT, SUNRISE, SUNSET; [] means any time.
      time: []
      # Weather: NONE, RAIN, THUNDER; [] means any weather.
      weather: []
    # Default lore used when a fish has no custom lore.
    lore:
      - '<gray>{length}cm</gray>'
  behavior:
    # Add an enchantment-like glint.
    glow: false
    # true blocks the interaction; false allows it.
    block:
      HOPPER: false
      CHEST: false
      CRAFTER: true
      ANVIL: true
    # true prevents the listed action or damage; false allows it.
    environment:
      DESTROYED_BY_CACTUS: true
      DESTROYED_BY_LAVA: true
      IS_EDIBLE: false
      PLACE: false
      DROP: false

fish:
  # Unique fish ID. Do not reuse an ID from another rarity file.
  river_carp:
    # Minecraft material used for the fish item.
    material: COD
    # Item name; supports MiniMessage text.
    displayName: '<#bf8d52>River Carp'
    # Optional CustomModelData for a resource pack.
    model-data: 20001
    # Optional namespaced ID for a resource-pack display/model.
    resource-pack-id: mypack:river_carp
    # Optional Base64 Mojang skin texture for a PLAYER_HEAD.
    # texture: 'BASE64_TEXTURE_PROPERTY'
    settings:
      # Relative catch weight; higher values make this fish appear more often.
      weight: 50
      # Catch size in centimeters; decimal precision is set in the main config.
      size:
        min: 40
        max: 80
      # Base fish price; multiplied by the rarity multiplier.
      worth: 8.5
      # Record the catch in angler statistics and the journal.
      fisherman: true
      journal: true
      # Hide notifications related to this fish.
      silent: false
    conditions:
      # Minecraft biomes or namespaced datapack keys.
      biome: [RIVER, FROZEN_RIVER]
      # DAY, NIGHT, SUNRISE, SUNSET.
      time: [DAY, SUNRISE]
      # NONE, RAIN, THUNDER.
      weather: [NONE, RAIN]
    # Custom lore; omitted keys use the rarity default.
    lore:
      - '<gray>{length}cm</gray>'
      - '<dark_gray>Caught by: {fisherman}</dark_gray>'
```

## Accepted values and catch weights

- **Rarity:** Use consistent IDs such as `common`, `rare`, `epic`, `legendary`, or `mythic`. Fish definitions and rod/bait filters must use matching IDs.
- **Material:** Use an uppercase Minecraft material name, such as `COD`, `PAPER`, or `PLAYER_HEAD`.
- **Name and lore:** Text values support MiniMessage, for example `<aqua>Fish Name</aqua>`. `{length}` can show the catch size; `{fisherman}` can show the angler's name.
- **Catch weight:** `weight` is not a percentage. For example, if fish A has weight `50` and fish B has weight `10`, fish A has a higher relative chance when both meet their conditions.
- **Size and price:** `min` and `max` set the size range in centimeters. The base `worth` is multiplied by the rarity's `worth-multi`.
- **Conditions:** Biomes can be Minecraft enum names such as `RIVER` or custom IDs such as `my_datapack:crystal_lake`. Time accepts `DAY`, `NIGHT`, `SUNRISE`, or `SUNSET`; weather accepts `NONE`, `RAIN`, or `THUNDER`.
- **Defaults and overrides:** `default_settings` provides common values. A fish-specific value with the same key overrides the default.

## Item protection keys

The example `block` section supports `CRAFTER`, `HOPPER`, `CHEST`, `ENDER_CHEST`, `ALL_SHULKER_BOX`, `ALL_BUNDLE`, `CRAFTING_TABLE`, `VILLAGER_TRADING`, `TRAPPED_CHEST`, `BARREL`, `PIGLIN_TRADES`, `PICKED_BY_COPPER_GOLEM`, `COPPER_CHEST`, `EXPOSED_COPPER_CHEST`, `WEATHERED_COPPER_CHEST`, `OXIDIZED_COPPER_CHEST`, the `WAXED_*` copper chest variants, `ANVIL`, `BEACON`, `BLAST_FURNACE`, `BREWING_STAND`, `DISPENSER`, `DROPPER`, `ENCHANTING_TABLE`, `FURNACE`, `GRINDSTONE`, `WEAR_CUSTOM_HEAD`, `WEAR_ARMOR`, `ITEM_FRAME`, and `GLOW_ITEM_FRAME`.

The `environment` section supports `DESTROYED_BY_CACTUS`, `DESTROYED_BY_LAVA`, `DESTROYED_BY_END_CRYSTAL`, `DESTROYED_BY_TNT_MINECART`, `DESTROYED_BY_WITHER_EXPLOSION`, `DESTROYED_BY_TNT`, `DESTROYED_BY_CREEPER`, `IS_EDIBLE`, `PLACE`, and `DROP`.

## Create a fish

1. Choose a rarity file, or copy one to create a new rarity group.
2. Add a fish ID under `fish:`. Use lowercase letters and underscores, for example `crystal_carp`.
3. Set `material`, `displayName`, `settings`, conditions, and lore.
4. For a resource-pack model, set `model-data` or `resource-pack-id`. For a head texture, use `PLAYER_HEAD` and add the Base64 texture.
5. Reload with `/fiofishing admin reload`, check the console, and give a test item with `/fiofishing admin give fish <id> <player> [amount]`.

Fish IDs must be unique across the entire Fish folder. To change a fish's rarity, move its definition to the matching rarity file and make sure its rarity ID matches.
