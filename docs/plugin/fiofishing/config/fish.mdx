# Create Custom Fishs

Buat dan ubah ikan di `plugins/FioFishing/Loots/Fish/*.yml`. File bawaan dikelompokkan berdasarkan rarity seperti `common.yml`, `rare.yml`, dan `mythic.yml`. Salin file contoh yang paling sesuai, lalu ubah nilai dan komentar sesuai kebutuhan.

## Struktur file ikan

```yaml
rarity:
  # ID rarity untuk fish, filter pancing, dan modifier umpan.
  id: common
  # Urutan rarity dalam menu; angka lebih kecil tampil dahulu.
  weight: 1
  # Pengali bobot semua ikan di file; 1 normal, 0 menonaktifkan peluangnya.
  catch-weight: 1
  # Pengali harga jual; 1 berarti harga normal.
  worth-multi: 1.0
  fih-animations:
    # Entity animasi yang muncul saat ikan rarity ini menggigit.
    entity: TROPICAL_FISH
  settings:
    broadcast:
      # Aktifkan pengumuman tangkapan rarity ini.
      enable: false
      # Jika true, pengumuman hanya saat pemancing memegang rod.
      if-only-holdingRods: true
      # Daftar aksi; contoh format tersedia di bawah.
      message:
        - '[MESSAGE] <gray>{player} mendapat {fish}</gray>'
        - '[SOUND] BLOCK_BUBBLE_COLUMN_BUBBLE_POP 1 1 master'
  default_settings:
    size:
      # Batas ukuran default ikan dalam cm.
      min: 1
      max: 20
    # Catat ikan pada statistik pemancing.
    fisherman: false
    # Catat ikan pada jurnal/perjalanan.
    journal: true
    # Harga dasar sebelum dikalikan worth-multi.
    worth: 0.50
    conditions:
      # Biome yang diizinkan; [] berarti semua biome.
      biome: []
      # Waktu: DAY, NIGHT, SUNRISE, SUNSET; [] berarti kapan saja.
      time: []
      # Cuaca: NONE, RAIN, THUNDER; [] berarti semua cuaca.
      weather: []
    # Lore default jika fish tidak punya lore sendiri.
    lore:
      - '<gray>{length}cm</gray>'
  behavior:
    # Kilau seperti enchantment.
    glow: false
    # true memblokir interaksi tersebut; false mengizinkan.
    block:
      HOPPER: false
      CHEST: false
      CRAFTER: true
      ANVIL: true
    # true mencegah aksi/kerusakan yang tertulis; false tidak mencegah.
    environment:
      DESTROYED_BY_CACTUS: true
      DESTROYED_BY_LAVA: true
      IS_EDIBLE: false
      PLACE: false
      DROP: false

fish:
  # ID unik ikan. Jangan gunakan ID yang sama di file rarity lain.
  river_carp:
    # Material Minecraft yang menjadi item ikan.
    material: COD
    # Nama item; menerima teks MiniMessage.
    displayName: '<#bf8d52>River Carp'
    # CustomModelData opsional untuk resource pack.
    model-data: 20001
    # ID namespaced opsional untuk tampilan/resource pack.
    resource-pack-id: mypack:river_carp
    # Opsional, untuk texture kepala PLAYER_HEAD: Base64 skin Mojang.
    # texture: 'BASE64_TEXTURE_PROPERTY'
    settings:
      # Bobot peluang relatif: semakin tinggi semakin sering muncul.
      weight: 50
      # Ukuran hasil dalam cm; config umum mengatur angka desimal.
      size:
        min: 40
        max: 80
      # Harga dasar ikan; dikalikan pengali rarity.
      worth: 8.5
      # Catat pada statistik pemancing dan jurnal.
      fisherman: true
      journal: true
      # Sembunyikan notifikasi terkait ikan ini.
      silent: false
    conditions:
      # Biome Minecraft atau key namespaced datapack.
      biome: [RIVER, FROZEN_RIVER]
      # DAY, NIGHT, SUNRISE, SUNSET.
      time: [DAY, SUNRISE]
      # NONE, RAIN, THUNDER.
      weather: [NONE, RAIN]
    # Lore khusus; jika dihilangkan, pakai lore default rarity.
    lore:
      - '<gray>{length}cm</gray>'
      - '<dark_gray>Ditangkap oleh: {fisherman}</dark_gray>'
```

## Opsi nilai dan cara mengatur peluang

- **Rarity:** gunakan ID konsisten seperti `common`, `rare`, `epic`, `legendary`, atau `mythic`. Nilai rarity pada contoh adalah nama yang harus sama dengan file/fish ID dan filter rod/bait.
- **Material:** nama material Minecraft huruf besar, misalnya `COD`, `PAPER`, atau `PLAYER_HEAD`.
- **Nama dan lore:** nilai teks menerima MiniMessage, misalnya `<aqua>Nama Ikan</aqua>`. `{length}` dapat menampilkan panjang tangkapan; `{fisherman}` dapat menampilkan nama pemancing.
- **Berat peluang:** nilai `weight` bukan persen. Misalnya ikan A berbobot `50` dan ikan B `10`, ikan A punya bobot relatif lebih besar jika keduanya memenuhi kondisi.
- **Ukuran dan harga:** `min`/`max` menentukan rentang ukuran cm. Harga dasar di `worth` dikalikan `worth-multi` pada rarity.
- **Syarat:** biome boleh nama enum Minecraft seperti `RIVER` atau ID custom seperti `my_datapack:crystal_lake`. Waktu hanya `DAY`, `NIGHT`, `SUNRISE`, `SUNSET`; cuaca hanya `NONE`, `RAIN`, `THUNDER`.
- **Default dan override:** `default_settings` menjadi nilai umum. Jika fish memiliki nilai sendiri dengan key yang sama, pengaturan fish itu yang dipakai.

## Key perlindungan item

Di dalam bagian `block`, key dari contoh file mencakup `CRAFTER`, `HOPPER`, `CHEST`, `ENDER_CHEST`, `ALL_SHULKER_BOX`, `ALL_BUNDLE`, `CRAFTING_TABLE`, `VILLAGER_TRADING`, `TRAPPED_CHEST`, `BARREL`, `PIGLIN_TRADES`, `PICKED_BY_COPPER_GOLEM`, `COPPER_CHEST`, `EXPOSED_COPPER_CHEST`, `WEATHERED_COPPER_CHEST`, `OXIDIZED_COPPER_CHEST`, versi `WAXED_*` dari copper chest, `ANVIL`, `BEACON`, `BLAST_FURNACE`, `BREWING_STAND`, `DISPENSER`, `DROPPER`, `ENCHANTING_TABLE`, `FURNACE`, `GRINDSTONE`, `WEAR_CUSTOM_HEAD`, `WEAR_ARMOR`, `ITEM_FRAME`, dan `GLOW_ITEM_FRAME`.

Di dalam bagian `environment`, key yang tersedia adalah `DESTROYED_BY_CACTUS`, `DESTROYED_BY_LAVA`, `DESTROYED_BY_END_CRYSTAL`, `DESTROYED_BY_TNT_MINECART`, `DESTROYED_BY_WITHER_EXPLOSION`, `DESTROYED_BY_TNT`, `DESTROYED_BY_CREEPER`, `IS_EDIBLE`, `PLACE`, dan `DROP`.

## Membuat ikan baru

1. Pilih file rarity yang sesuai, atau salin salah satu file rarity untuk membuat kelompok baru.
2. Tambahkan fish ID di bawah `fish:`. Gunakan huruf kecil dan underscore, misalnya `crystal_carp`.
3. Atur `material`, `displayName`, `settings`, kondisi, dan lore.
4. Jika memakai model resource pack, isi `model-data` atau `resource-pack-id`. Untuk kepala, gunakan `PLAYER_HEAD` dan isi texture Base64.
5. Reload dengan `/fiofishing admin reload`; cek console dan berikan sampel dengan `/fiofishing admin give fish <id> <pemain> [jumlah]`.

Fish ID harus unik di seluruh folder Fish. Untuk mengubah rarity ikan, pindahkan definisinya ke file rarity yang sesuai dan pastikan nilai ID rarity cocok.
