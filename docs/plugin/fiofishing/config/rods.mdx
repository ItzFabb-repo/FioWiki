# Pancing

File pancing berada di `plugins/FioFishing/Loots/Rods/`. Satu file `.yml` mendefinisikan satu rod. Salin contoh yang ada, ubah ID, nilai durability, daftar ikan/rarity/bait, suara, dan tampilan item.

## Struktur file rod

```yaml
fishingRods:
  # Rarity untuk kelompok/tampilan rod.
  rarity: common
  # ID unik untuk perintah give, menu, dan daftar bait.
  id: wooden_rod
  # Nama tampilan MiniMessage.
  display-name: '<white>Wooden Rod</white>'
  # Terapkan setting ke rod vanilla tanpa data custom.
  # Hanya boleh true di satu file rod.
  default_vanilla: true
  item:
    # Rod memakai material FISHING_ROD.
    material: FISHING_ROD
    custom:
      # VANILLA, ITEMSADDER, ORAXEN, NEXO.
      type: VANILLA
      # CustomModelData untuk model vanilla.
      modelData: 0
      # ID item model vanilla, contoh custom_rods:wooden_rod.
      itemModel: custom_rods:wooden_rod
      # ID item plugin eksternal jika type bukan VANILLA.
      # custom: mypack:wooden_rod
  settings:
    durability:
      # Aktifkan durability custom FioFishing.
      enable: true
      # Durability maksimum rod.
      value: 30
      dura-loss:
        # Kehilangan umum jika tidak ada nilai khusus untuk hasil.
        loss-per-catch: 1
        # Kehilangan pada reel gagal dan junk.
        loss-on-failed-catch: 0
        loss-on-junk: 1
        # Kehilangan per rarity ikan.
        loss-on-common: 2
        loss-on-uncommon: 2
        loss-on-rare: 2
        loss-on-epic: 2
        loss-on-legendary: 2
        loss-on-mythic: 2
    enchants:
      # Jika whitelist tidak kosong, hanya enchantment di sini yang diizinkan.
      whitelist: []
      # Enchantment yang selalu ditolak.
      blacklist: [MENDING, UNBREAKING]
    others:
      # Izinkan loot memancing vanilla.
      allow-vanilla-loot: false
      # Izinkan perbaikan di anvil.
      allow-anvil-repair: true
      # Jatuhkan rod ketika pemilik mati.
      drop-on-death: true
    sound:
      # Setiap aksi cast/reel/bite/broken menerima enable, sound, volume, pitch.
      cast:
        enable: true
        sound: entity.fishing_bobber.throw
        volume: 1.0
        pitch: 1.0
      reel:
        enable: true
        sound: entity.fishing_bobber.retrieve
        volume: 1.0
        pitch: 1.0
      bite:
        enable: true
        sound: entity.fishing_bobber.splash
        volume: 1.0
        pitch: 1.0
      broken:
        enable: true
        sound: entity.item.break
        volume: 1.0
        pitch: 1.0
    allowed:
      fish:
        # Filter fish ID. '*' berarti semua ikan.
        enable: true
        list: ['*']
      rarities:
        # Filter ID rarity. '*' berarti semua rarity.
        enable: false
        list: ['*']
      # ID bait yang boleh dipasang pada rod.
      baits: [worm, shrimp]
  # Baris deskripsi item. Mendukung MiniMessage dan placeholder bawaan rod.
  lore:
    - '<gray>Pancing untuk menangkap ikan.</gray>'
    - '%baits%'
```

## Pilihan dan cara mengatur

- **Durability:** `enable` menerima boolean; `value` dan seluruh nilai `dura-loss` berupa angka bulat. `loss-on-*` mengatur kehilangan khusus untuk hasil tertentu; jika hasil tidak memiliki nilai khusus, plugin memakai `loss-per-catch`.
- **Enchantment:** tulis nama enchantment Minecraft huruf besar seperti `LURE`, `LUCK_OF_THE_SEA`, `UNBREAKING`, `MENDING`. Whitelist kosong berarti tidak membatasi berdasarkan whitelist; blacklist tetap melarang nilai yang tertulis.
- **Perilaku umum:** semua key di `others` menerima `true`/`false`.
- **Suara:** sound harus nama sound Minecraft valid. Volume dan pitch berupa angka; `1.0` adalah normal. Matikan satu suara dengan `enable: false`.
- **Filter ikan/rarity:** daftar menggunakan ID internal dari file ikan. Agar semua diterima, gunakan `'*'`. Jika filter dinyalakan, isi daftar dengan ID yang ingin diterima.
- **Bait:** daftar menggunakan ID yang tertulis sebagai `id` di bawah bagian `baits` dan `settings`. Daftar kosong berarti tidak ada bait yang diizinkan pada rod.
- **Tampilan:** `VANILLA` memakai `modelData` atau `itemModel`; `ITEMSADDER`, `ORAXEN`, `NEXO` memakai ID item dari plugin tersebut.

Contoh membatasi rod pada dua ikan dan satu rarity:

```yaml
settings:
  allowed:
    fish:
      enable: true
      list:
        - river_carp
        - crystal_koi
    rarities:
      enable: true
      list:
        - rare
    baits:
      - golden_worm
```

Hanya satu rod boleh memakai `default_vanilla: true`. Rod baru dapat diberikan dengan `/fiofishing admin give fishingrods <id> <pemain> [jumlah]`. ID tersebut harus sama dengan key `id` di bawah `fishingRods`.
