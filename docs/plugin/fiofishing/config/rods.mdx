# Fishing Rods

Rod files are stored in `plugins/FioFishing/Loots/Rods/`. Each `.yml` file defines one rod. Copy an existing example, then change its ID, durability, fish/rarity/bait lists, sounds, and item appearance.

## Rod file structure

```yaml
fishingRods:
  # Rarity used to group or display this rod.
  rarity: common
  # Unique ID used by the give command, menus, and bait lists.
  id: wooden_rod
  # MiniMessage display name.
  display-name: '<white>Wooden Rod</white>'
  # Apply these settings to vanilla rods without custom data.
  # Only one rod file may set this to true.
  default_vanilla: true
  item:
    # The rod uses the FISHING_ROD material.
    material: FISHING_ROD
    custom:
      # VANILLA, ITEMSADDER, ORAXEN, or NEXO.
      type: VANILLA
      # CustomModelData for a vanilla model.
      modelData: 0
      # Vanilla item model ID, for example custom_rods:wooden_rod.
      itemModel: custom_rods:wooden_rod
      # External plugin item ID when type is not VANILLA.
      # custom: mypack:wooden_rod
  settings:
    durability:
      # Enable FioFishing custom rod durability.
      enable: true
      # Maximum rod durability.
      value: 30
      dura-loss:
        # General loss when no catch-specific value is set.
        loss-per-catch: 1
        # Loss for a failed reel and junk catches.
        loss-on-failed-catch: 0
        loss-on-junk: 1
        # Loss for each fish rarity.
        loss-on-common: 2
        loss-on-uncommon: 2
        loss-on-rare: 2
        loss-on-epic: 2
        loss-on-legendary: 2
        loss-on-mythic: 2
    enchants:
      # When not empty, only enchantments in this whitelist are allowed.
      whitelist: []
      # Enchantments that are always denied.
      blacklist: [MENDING, UNBREAKING]
    others:
      # Allow vanilla fishing loot.
      allow-vanilla-loot: false
      # Allow repairs in an anvil.
      allow-anvil-repair: true
      # Drop the rod when its owner dies.
      drop-on-death: true
    sound:
      # Each cast/reel/bite/broken action supports enable, sound, volume, and pitch.
      cast:
        enable: true
        sound: entity.fishing_bobber.throw
        volume: 1.0
        pitch: 1.0
      reel:
        enable: true
        sound: entity.fishing_bobber.retrieve
        volume: 1.0
        pitch: 1.0
      bite:
        enable: true
        sound: entity.fishing_bobber.splash
        volume: 1.0
        pitch: 1.0
      broken:
        enable: true
        sound: entity.item.break
        volume: 1.0
        pitch: 1.0
    allowed:
      fish:
        # Filter by fish ID. '*' means all fish.
        enable: true
        list: ['*']
      rarities:
        # Filter by rarity ID. '*' means all rarities.
        enable: false
        list: ['*']
      # Bait IDs that can be attached to this rod.
      baits: [worm, shrimp]
  # Item description lines support MiniMessage and built-in rod placeholders.
  lore:
    - '<gray>A rod for catching fish.</gray>'
    - '%baits%'
```

## Options and configuration

- **Durability:** `enable` accepts a boolean; `value` and all `dura-loss` values are integers. `loss-on-*` sets the loss for a specific result. When no result-specific value is set, the plugin uses `loss-per-catch`.
- **Enchantments:** Use uppercase Minecraft enchantment names such as `LURE`, `LUCK_OF_THE_SEA`, `UNBREAKING`, or `MENDING`. An empty whitelist adds no whitelist restriction; the blacklist still denies listed values.
- **General behavior:** Every key under `others` accepts `true` or `false`.
- **Sounds:** Sound values must be valid Minecraft sound names. Volume and pitch are numeric; `1.0` is normal. Disable an individual sound with `enable: false`.
- **Fish and rarity filters:** Lists use internal IDs from the fish files. Use `'*'` to allow everything. When a filter is enabled, list the IDs it should accept.
- **Bait:** The list uses the ID under `baits.settings` in each bait file. An empty list means no bait can be attached to this rod.
- **Appearance:** `VANILLA` uses `modelData` or `itemModel`; `ITEMSADDER`, `ORAXEN`, and `NEXO` use item IDs from those plugins.

Example: limit a rod to two fish and one rarity.

```yaml
settings:
  allowed:
    fish:
      enable: true
      list:
        - river_carp
        - crystal_koi
    rarities:
      enable: true
      list:
        - rare
    baits:
      - golden_worm
```

Only one rod can set `default_vanilla: true`. Give a new rod with `/fiofishing admin give fishingrods <id> <player> [amount]`. The ID must match the `id` key under `fishingRods`.
