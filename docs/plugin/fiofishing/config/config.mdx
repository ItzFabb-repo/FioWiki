# `config.yml`

File ini berada di `plugins/FioFishing/config.yml`. Isinya mengatur perilaku global. Boolean diisi `true` atau `false`, angka tanpa tanda kutip, dan daftar ditulis sebagai YAML list.

```yaml
settings:
  enabled-worlds: []
  language: id
  announce-rare-catches: true
```

Setelah mengubah file ini, jalankan `/fiofishing admin reload`. Jika mengubah pengaturan koneksi database, lakukan restart server.

## Pengaturan pada tingkat utama

| Key | Tipe/nilai | Fungsi |
| --- | --- | --- |
| `force-update-config` | `true` / `false` | Jika `true`, file config bawaan dapat menimpa/memperbarui config server pada startup. Normalnya biarkan `false`. Buat backup sebelum mengaktifkan. |
| `config-version` | Angka versi | Penanda internal plugin. Jangan diubah. |
| `command-aliases` | Daftar teks | Alias tambahan untuk perintah. Perintah `/fiofishing` selalu tersedia; bawaan mencantumkan `ffishing` dan `fiofishing`. |

## Animasi memancing: `fih-animation`

Nama section dan beberapa key memang dieja `fih`/`fihing` pada file plugin.

| Key | Tipe/nilai | Fungsi |
| --- | --- | --- |
| `should-fih-have-animation-when-fihing` | Boolean | Menyalakan animasi ikan visual di sekitar bobber. |
| `smooth-movement` | Boolean | Membuat gerakan animasi lebih halus. |
| `wander-speed` | Desimal | Kecepatan visual saat ikan berenang biasa. |
| `lured-speed` | Desimal | Kecepatan saat ikan mendekati umpan. |
| `bite-speed` | Desimal | Kecepatan visual saat ikan menggigit. |
| `bite-visual-distance` | Desimal | Jarak visual ikan dari bobber saat menggigit. |
| `ready-indicator.enabled` | Boolean | Menampilkan indikator air saat siap menarik ikan. |
| `ready-indicator.duration-ticks` | Bilangan bulat | Lama indikator tampil dalam tick (20 tick = 1 detik). |
| `ready-indicator.interval-ticks` | Bilangan bulat | Jarak antar efek indikator dalam tick. |

Untuk mematikan fitur, gunakan `enabled: false` atau key boolean yang sesuai; jangan menghapus parent section jika hanya ingin mematikan satu bagian.

## Dunia, bahasa, dan interaksi

| Key | Opsi yang diterima | Fungsi |
| --- | --- | --- |
| `settings.enabled-worlds` | Daftar nama world; `[]` | Daftar world tempat fitur memancing aktif. Daftar kosong berarti semua world. Contoh: `[world, world_nether]`. |
| `settings.language` | `en`, `id`, `jp`, `ch` | Memilih file `Lang/messages_<kode>.yml`. |
| `settings.announce-rare-catches` | Boolean | Mengumumkan tangkapan langka ke pemain lain. |
| `settings.interaction.manage-baits` | `Q`, `SHIFT_Q`, `LEFT_CLICK`, `SHIFT_LEFT_CLICK`, `RIGHT_CLICK`, `SHIFT_RIGHT_CLICK`, `SHIFT` | Aksi untuk mengelola/melepas bait dari pancing. |
| `settings.interaction.apply-baits` | `LEFT_CLICK_DRAG`, `RIGHT_CLICK_DRAG`, `ANY_CLICK_DRAG` | Gesture inventory untuk memasang bait ke pancing. |
| `settings.durability-break-warning.enabled` | Boolean | Mengaktifkan peringatan durability rod yang hampir habis. |
| `settings.durability-break-warning.threshold-percent` | Angka persen, contoh `10` | Ambang sisa durability saat peringatan muncul. |

Contoh membatasi fitur ke world tertentu:

```yaml
settings:
  enabled-worlds:
    - world
    - fishing_world
```

## Fitur AFK

### Perintah AFK

`settings.afk-feature.enabled` menyalakan fitur perintah `/fiofishing afk`. `settings.afk-feature.permission` menentukan permission yang diperlukan; default-nya `fiofishing.command.afk`. Fitur ini ditujukan untuk dipakai saat `settings.anti-afk-fishing.enabled` bernilai `false`.

### Tantangan anti-AFK otomatis

| Key | Tipe/nilai | Fungsi |
| --- | --- | --- |
| `settings.anti-afk-fishing.enabled` | Boolean | Menantang pemain yang diam terlalu lama sebelum diizinkan memancing lagi. |
| `idle-seconds` | Detik | Lama tidak aktif sebelum tantangan dimulai. |
| `bypass-permission` | Nama permission | Permission yang melewati tantangan dan hukumannya. |
| `challenge.steps` | Bilangan bulat | Jumlah input berurutan yang harus dilakukan. |
| `challenge.input-timeout-seconds` | Detik | Batas waktu untuk setiap input. |
| `challenge.display-refresh-ticks` | Tick | Interval pembaruan tampilan hitung mundur. |
| `indicators.sneak`, `indicators.jump` | Teks/simbol | Simbol yang ditampilkan untuk input Sneak dan Jump. |
| `actions.sneak`, `actions.jump` | Teks | Nama aksi yang ditampilkan di subtitle. |
| `verify.title`, `verify.subtitle` | MiniMessage | Tampilan saat pemain menyelesaikan tantangan. Placeholder: `{indicator}`, `{action}`, `{timeout}`. |
| `failed.title`, `failed.subtitle` | MiniMessage | Tampilan ketika input salah atau terlambat. |
| `success.title`, `success.subtitle` | MiniMessage | Tampilan saat tantangan berhasil. |
| `failed-display-ticks` | Tick | Berapa lama pesan gagal ditampilkan. |
| `title-timings.fade-in-ticks`, `stay-ticks`, `fade-out-ticks` | Tick | Durasi animasi title. |
| `punishment.enabled` | Boolean | Mengaktifkan penalti setelah jumlah kegagalan tertentu. |
| `punishment.punished` | Peta `jumlah-gagal: [durasi]` | Ambang gagal dan durasi hukuman. Durasi contoh menggunakan `60s`, `180s`. |
| `punishment.title`, `subtitle` | MiniMessage | Pesan ketika pemain sedang dihukum; subtitle dapat memakai `{remaining}`. |

## Papan peringkat dan statistik pribadi

Semua opsi berada di `settings.leaderboard`.

| Key | Opsi | Fungsi |
| --- | --- | --- |
| `enabled` | Boolean | Menampilkan papan peringkat event. |
| `distance` | Desimal/jarak blok | Jarak papan ditampilkan kepada pemain. |
| `max-entries` | Bilangan bulat | Jumlah peserta teratas yang ditampilkan. |
| `refresh-seconds` | Detik | Interval pembaruan data. |
| `sneak-freeze.enabled` | Boolean | Mengizinkan pemain menahan Sneak untuk membekukan tampilan sementara. |
| `rank-change.enabled` | Boolean | Menampilkan perubahan posisi peringkat. |
| `rank-change.append-to-entry` | Boolean | Menambahkan teks perubahan posisi pada baris entri secara otomatis. |
| `rank-change.up`, `down`, `unchanged`, `new` | Teks MiniMessage | Format saat naik, turun, tetap, atau baru muncul. `{change}` adalah jumlah posisi berubah. |
| `score-format.catches`, `size`, `bait` | Teks MiniMessage | Format skor sesuai jenis event; gunakan `{value}` untuk nilai skor. |
| `line` | Daftar baris teks | Seluruh tampilan papan. Placeholder penting: `{eventName}`, `{player_1}`–`{player_10}`, `{fish_1}`–`{fish_10}`, `{score_1}`–`{score_10}`, `{position}`, `{when}`. |
| `personal-stats.enabled` | Boolean | Menampilkan statistik pribadi di sisi papan. |
| `personal-stats.labels-offset` | Desimal/blok | Jarak horizontal label statistik dari papan. |
| `personal-stats.labels` | Daftar baris teks | Template statistik. Placeholder: `{eventName}`, `{position}`, `{catches}`, `{score}`. |
| `personal-stats.fishHistory.maxShown` | Bilangan bulat | Jumlah maksimal tangkapan terbaru yang ditampilkan. |
| `personal-stats.fishHistory.position` | Peta nomor ke teks | Simbol/nama untuk setiap urutan ikan. |

Dalam `labels`, blok `<only-shown-if-existed>` mengapit bagian riwayat yang hanya ditampilkan jika ada isinya. Di dalam format riwayat, `{pos}`, `{fishColor}`, `{fish}`, dan `{size}` adalah placeholder.

## Format ukuran ikan

Bagian `settings.fish-size` mengatur angka panjang ikan.

| Key | Opsi/nilai | Fungsi |
| --- | --- | --- |
| `decimal-enabled` | Boolean | `false` menghasilkan ukuran bulat; `true` memungkinkan desimal. |
| `decimal-mode` | `RANDOM` atau `LIST` | Pilih angka desimal acak atau ambil dari daftar. |
| `decimal-places` | `0`–`3` | Banyak angka di belakang koma. |
| `random-min`, `random-max` | Bilangan bulat inklusif | Batas bagian desimal dalam presisi terpilih. Pada dua digit, `0`–`99` berarti `.00`–`.99`. |
| `decimal-values` | Daftar bilangan bulat | Pilihan desimal untuk mode `LIST`; pada dua digit, nilai `5` berarti `.05`. |
| `trim-trailing-zeroes` | Boolean | Menghapus nol di akhir, misalnya `8.50` menjadi `8.5`. |

Contoh: gunakan `decimal-mode: LIST`, `decimal-places: 2`, dan `decimal-values: [0, 5, 15, 95]` untuk membatasi ukuran pada `.00`, `.05`, `.15`, atau `.95`.

## Lama waktu dan penyimpanan

`settings.time-units` menerima teks untuk bentuk tunggal/jamak dari `second`, `minute`, `hour`, `day`, `week`, `month`, dan `year`. Nilai bawaan berupa singkatan seperti `s`, `m`, `h`, `d`, `w`, `mo`, `y`.

| Key | Opsi | Fungsi |
| --- | --- | --- |
| `storage.type` | `YAML` atau `MYSQL` | Memilih penyimpanan data pemain. |
| `storage.mysql.host` | Hostname/IP | Alamat database. |
| `port` | Bilangan bulat | Port MySQL, umum `3306`. |
| `database` | Nama database | Database tujuan. |
| `username`, `password` | Teks | Kredensial database. |
| `table` | Nama tabel | Tabel data FioFishing. |
| `pool-size` | Bilangan bulat | Maksimum koneksi pool. |

Mode `YAML` menyimpan data di `data.yml`. Perubahan tipe penyimpanan tidak menyalin data otomatis. Backup data dan lakukan migrasi manual sebelum mengganti backend.
