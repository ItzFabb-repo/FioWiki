# `config.yml`

File ini berada di `plugins/FioFishing/config.yml`. Pengaturan ditampilkan dalam struktur bertingkat seperti di bawah. Baris komentar `#` menerangkan nilai di bawahnya; komentar tidak perlu disalin bila tidak dibutuhkan.

Setelah mengedit, jalankan `/fiofishing admin reload`. Pengaturan koneksi database sebaiknya diubah ketika server mati lalu dilanjutkan dengan restart.

## Bagian utama dan animasi

```yaml
# Set true hanya jika ingin file bawaan memperbarui/menimpa config saat startup.
force-update-config: false
# Versi internal plugin. Jangan diubah.
config-version: 3

# Alias tambahan. Perintah /fiofishing tetap tersedia walau daftar ini kosong.
command-aliases:
  - ffishing
  - fiofishing

# Key animasi pada file memang ditulis fih/fihing.
fih-animation:
  # Aktifkan animasi ikan visual saat memancing.
  should-fih-have-animation-when-fihing: true
  # Gerakkan entity animasi dengan lebih halus.
  smooth-movement: true
  # Kecepatan visual pada tiap fase; desimal dalam blok per tick.
  wander-speed: 0.10
  lured-speed: 0.17
  bite-speed: 0.20
  # Jarak ikan visual dari bobber saat menggigit.
  bite-visual-distance: 0.45
  ready-indicator:
    # Efek air ketika ikan siap ditarik.
    enabled: true
    # Lama efek dan jarak antar efek, dihitung dalam tick (20 tick = 1 detik).
    duration-ticks: 14
    interval-ticks: 3
```

Untuk key boolean, gunakan `true` atau `false`. Nilai `force-update-config` biasanya tetap `false`; membuatnya `true` dapat mengganti perubahan server dengan konfigurasi bundled ketika server mulai.

## Dunia, bahasa, pengumuman, dan interaksi

```yaml
settings:
  # Fitur memancing hanya aktif di world yang tertulis di sini.
  # [] berarti semua world. Isi dengan nama world yang tepat.
  enabled-worlds: []

  # Pilih file pesan: en, id, jp, ch; kode custom juga bisa dibuat.
  language: en

  # Umumkan tangkapan langka ke pemain lain.
  announce-rare-catches: true

  interaction:
    # Aksi melepas/mengelola umpan: Q, SHIFT_Q, LEFT_CLICK,
    # SHIFT_LEFT_CLICK, RIGHT_CLICK, SHIFT_RIGHT_CLICK, SHIFT.
    manage-baits: SHIFT_Q
    # Gesture inventori untuk memasang umpan: LEFT_CLICK_DRAG,
    # RIGHT_CLICK_DRAG, ANY_CLICK_DRAG.
    apply-baits: LEFT_CLICK_DRAG

  durability-break-warning:
    # Aktifkan pesan ketika durability rod hampir habis.
    enabled: true
    # Ambang sisa durability dalam persen.
    threshold-percent: 10.0
```

Contoh mengaktifkan plugin hanya di dua world:

```yaml
settings:
  enabled-worlds:
    - world
    - fishing_world
```

## Perintah AFK dan tantangan otomatis

```yaml
settings:
  afk-feature:
    # Fitur perintah /fiofishing afk; gunakan saat anti-AFK otomatis mati.
    enabled: true
    # Permission untuk perintah AFK.
    permission: fiofishing.command.afk

  anti-afk-fishing:
    # Menantang pemain yang diam lama sebelum boleh memancing lagi.
    enabled: false
    # Diam selama ini sebelum tantangan muncul.
    idle-seconds: 120
    # Permission untuk melewati tantangan dan hukumannya.
    bypass-permission: fiofishing.bypass.anti-afk-fishing
    challenge:
      # Jumlah input Sneak/Jump dalam satu tantangan.
      steps: 5
      # Batas waktu tiap input dalam detik.
      input-timeout-seconds: 60
      # Frekuensi pembaruan title dalam tick.
      display-refresh-ticks: 1
    indicators:
      # Simbol input pada title.
      sneak: '↓'
      jump: '↑'
    actions:
      # Teks aksi pada subtitle.
      sneak: '(Sneak)'
      jump: '(Jump)'
    verify:
      # Saat tantangan berjalan. Placeholder: {indicator}, {action}, {timeout}.
      title: '{indicator} <gray><italic>({timeout}s)</italic></gray>'
      subtitle: '<gold>{action}</gold>'
    failed:
      # Pesan saat input salah atau melewati batas waktu.
      title: '<red>Verifikasi gagal!</red>'
      subtitle: '<gray>Coba urutan baru.</gray>'
    success:
      # Pesan saat tantangan berhasil.
      title: '<green>Berhasil!</green>'
      subtitle: '<gray>Kamu bisa memancing lagi.</gray>'
    # Lama pesan gagal tampil dalam tick.
    failed-display-ticks: 20
    title-timings:
      # Animasi masuk, lama tampil, dan animasi keluar dalam tick.
      fade-in-ticks: 0
      stay-ticks: 30
      fade-out-ticks: 0
    punishment:
      # Matikan agar tantangan tetap ada tanpa memberi penalti.
      enabled: true
      # Ambang jumlah kegagalan : durasi hukuman. Contoh format durasi: 60s.
      punished:
        3: ['60s']
        5: ['180s']
        8: ['300s']
        10: ['600s']
        15: ['1800s']
        20: ['3600s']
      # {remaining} menunjukkan waktu hukuman yang tersisa.
      title: '<dark_red><bold>Memancing diblokir!</bold></dark_red>'
      subtitle: '<white>Tunggu {remaining}</white>'
```

Nilai durasi ditulis sebagai teks seperti `'60s'`; angka di kiri pada `punished` adalah jumlah kegagalan yang memicu durasi tersebut. Untuk mematikan sistem tantangan otomatis, ubah `enabled` di dalam bagian `anti-afk-fishing` menjadi `false`.

## Leaderboard dan statistik pribadi

```yaml
settings:
  leaderboard:
    # Menampilkan leaderboard event.
    enabled: true
    # Jarak tampilan dalam blok, jumlah entri, dan interval pembaruan detik.
    distance: 6.0
    max-entries: 10
    refresh-seconds: 60
    sneak-freeze:
      # Sneak membekukan tampilan agar pemain bisa membaca.
      enabled: true
    rank-change:
      # Format perpindahan posisi leaderboard.
      enabled: true
      # Tambahkan indikator ke baris pemain secara otomatis.
      append-to-entry: true
      # {change} adalah jumlah posisi berubah.
      up: ' <green>(↑+{change})</green>'
      down: ' <red>(↓-{change})</red>'
      unchanged: ''
      new: '<green>♦</green>'
    score-format:
      # {value} adalah skor mentah.
      catches: '<yellow>{value}</yellow> <white>ikan</white>'
      size: '<yellow>{value}</yellow> <white>cm</white>'
      bait: '<yellow>{value}</yellow> <white>umpan</white>'
    # Susun baris leaderboard; tersedia eventName, player_1..10,
    # fish_1..10, score_1..10, position, when, rankChange_1..10.
    line:
      - '<dark_aqua><bold>Leaderboard Memancing</bold></dark_aqua>'
      - '<white>{player_1}</white> - <aqua>{fish_1}</aqua> - {score_1}'
      - '<gray>Posisi kamu: #{position}</gray>'
      - '<gray>Pembaruan dalam {when}</gray>'
    personal-stats:
      # Panel statistik pribadi di sisi leaderboard.
      enabled: true
      # Jarak horizontal dari papan dalam blok.
      labels-offset: 4.5
      # Placeholder: eventName, position, catches, score.
      labels:
        - '<yellow><bold>Statistik Pribadi</bold></yellow>'
        - '<white>Posisi:</white> #{position}'
        - '<white>Ikan:</white> {catches}'
        - '<white>Skor:</white> {score}'
        - '<only-shown-if-existed>'
        - '{pos} {fishColor}{fish} - {size}cm'
        - '</only-shown-if-existed>'
      fishHistory:
        # Maksimum ikan terakhir yang ditampilkan.
        maxShown: 5
        # Simbol yang dipakai untuk posisi riwayat.
        position:
          '1': '①'
          '2': '②'
          '3': '③'
          '4': '④'
          '5': '⑤'
```

Dalam template `line`, gunakan baris satu sampai sepuluh sesuai jumlah `max-entries`. Tag dan placeholder adalah teks yang tampil pada papan; ubah teks tanpa mengganti nama placeholder jika masih ingin nilainya otomatis diisi.

## Ukuran ikan dan label durasi

```yaml
settings:
  fish-size:
    # false = ukuran bulat; true = ukuran desimal.
    decimal-enabled: true
    # RANDOM memilih desimal dari rentang; LIST memilih dari decimal-values.
    decimal-mode: RANDOM
    # Presisi desimal 0 sampai 3 digit.
    decimal-places: 2
    # Batas rentang desimal inklusif; untuk dua digit 0..99 berarti .00.. .99.
    random-min: 0
    random-max: 99
    # Nilai desimal untuk mode LIST; pada 2 digit angka 5 berarti .05.
    decimal-values: [0, 5, 15, 95]
    # Hilangkan nol di belakang, mis. 8.50 menjadi 8.5.
    trim-trailing-zeroes: true

  # Label unit sisa waktu. Ubah nilainya menjadi kata lengkap bila diinginkan.
  time-units:
    second: 's'
    seconds: 's'
    minute: 'm'
    minutes: 'm'
    hour: 'h'
    hours: 'h'
    day: 'd'
    days: 'd'
    week: 'w'
    weeks: 'w'
    month: 'mo'
    months: 'mo'
    year: 'y'
    years: 'y'
```

`decimal-mode` menerima `RANDOM` atau `LIST`. Presisi desimal `decimal-places` menerima `0`, `1`, `2`, atau `3`. Dalam mode `LIST`, nilai yang tidak sesuai jumlah digit akan diformat mengikuti presisi yang dipilih.

## Penyimpanan data

```yaml
storage:
  # YAML menyimpan data pada data.yml; MYSQL menyimpan di database.
  type: YAML
  mysql:
    # Alamat/port database serta kredensial.
    host: localhost
    port: 3306
    database: minecraft
    username: root
    password: ''
    # Nama tabel dan ukuran connection pool.
    table: fiofishing_players
    pool-size: 5
```

Key `type` di dalam bagian `storage` menerima `YAML` atau `MYSQL`. Pergantian backend tidak memindahkan isi `data.yml` secara otomatis. Cadangkan data dan migrasikan lebih dulu jika ingin mempertahankan statistik pemain.
