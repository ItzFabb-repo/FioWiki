# `config.yml`

This file is located at `plugins/FioFishing/config.yml`. Settings are shown below in their nested structure. The `#` comments explain the values; copy them only if you want to keep the notes in your own file.

After editing, run `/fiofishing admin reload`. Change database connection settings while the server is stopped, then restart it.

## Main settings and animations

```yaml
# Set to true only if bundled defaults should update or overwrite the config at startup.
force-update-config: false
# Internal plugin version. Do not change this value.
config-version: 3

# Additional aliases. The /fiofishing command remains available even when this list is empty.
command-aliases:
  - ffishing
  - fiofishing

# The animation key is spelled fih/fihing in the configuration file.
fih-animation:
  # Enable the visual fish animation while fishing.
  should-fih-have-animation-when-fihing: true
  # Move the animated entity more smoothly.
  smooth-movement: true
  # Visual speed for each phase; decimal values are blocks per tick.
  wander-speed: 0.10
  lured-speed: 0.17
  bite-speed: 0.20
  # Distance between the visual fish and the bobber when it bites.
  bite-visual-distance: 0.45
  ready-indicator:
    # Water effect shown when the fish is ready to reel in.
    enabled: true
    # Effect duration and spacing in ticks (20 ticks = 1 second).
    duration-ticks: 14
    interval-ticks: 3
```

Boolean keys accept `true` or `false`. Keep `force-update-config` set to `false` in most cases; setting it to `true` can overwrite server changes with bundled defaults when the server starts.

## Worlds, language, announcements, and interactions

```yaml
settings:
  # Fishing is enabled only in the worlds listed here.
  # [] means all worlds. Use the exact world names.
  enabled-worlds: []

  # Select a message file: en, id, jp, ch. Custom language codes can also be created.
  language: en

  # Announce rare catches to other players.
  announce-rare-catches: true

  interaction:
    # Gestures for removing/managing bait: Q, SHIFT_Q, LEFT_CLICK,
    # SHIFT_LEFT_CLICK, RIGHT_CLICK, SHIFT_RIGHT_CLICK, SHIFT.
    manage-baits: SHIFT_Q
    # Inventory gestures for attaching bait: LEFT_CLICK_DRAG,
    # RIGHT_CLICK_DRAG, ANY_CLICK_DRAG.
    apply-baits: LEFT_CLICK_DRAG

  durability-break-warning:
    # Show a warning when rod durability is nearly depleted.
    enabled: true
    # Remaining durability threshold, as a percentage.
    threshold-percent: 10.0
```

Example: enable the plugin in only two worlds.

```yaml
settings:
  enabled-worlds:
    - world
    - fishing_world
```

## AFK command and automatic challenge

```yaml
settings:
  afk-feature:
    # Enable the /fiofishing afk command; use this when automatic anti-AFK is disabled.
    enabled: true
    # Permission required for the AFK command.
    permission: fiofishing.command.afk

  anti-afk-fishing:
    # Challenge players who have been idle for too long before allowing them to fish again.
    enabled: false
    # Idle time before the challenge appears.
    idle-seconds: 120
    # Permission to bypass the challenge and its penalties.
    bypass-permission: fiofishing.bypass.anti-afk-fishing
    challenge:
      # Number of Sneak/Jump inputs in one challenge.
      steps: 5
      # Time limit for each input, in seconds.
      input-timeout-seconds: 60
      # Title refresh interval in ticks.
      display-refresh-ticks: 1
    indicators:
      # Input symbols shown in the title.
      sneak: '↓'
      jump: '↑'
    actions:
      # Action labels shown in the subtitle.
      sneak: '(Sneak)'
      jump: '(Jump)'
    verify:
      # Shown while the challenge is active. Placeholders: {indicator}, {action}, {timeout}.
      title: '{indicator} <gray><italic>({timeout}s)</italic></gray>'
      subtitle: '<gold>{action}</gold>'
    failed:
      # Shown when an input is incorrect or the time limit is exceeded.
      title: '<red>Verification failed!</red>'
      subtitle: '<gray>Try a new sequence.</gray>'
    success:
      # Shown when the challenge is completed successfully.
      title: '<green>Success!</green>'
      subtitle: '<gray>You can fish again.</gray>'
    # How long the failure message remains visible, in ticks.
    failed-display-ticks: 20
    title-timings:
      # Fade-in, display, and fade-out durations in ticks.
      fade-in-ticks: 0
      stay-ticks: 30
      fade-out-ticks: 0
    punishment:
      # Disable penalties while keeping the challenge active.
      enabled: true
      # Failure-count threshold: penalty duration. Example duration format: 60s.
      punished:
        3: ['60s']
        5: ['180s']
        8: ['300s']
        10: ['600s']
        15: ['1800s']
        20: ['3600s']
      # {remaining} displays the remaining penalty time.
      title: '<dark_red><bold>Fishing is blocked!</bold></dark_red>'
      subtitle: '<white>Wait {remaining}</white>'
```

Write durations as text, such as `'60s'`. The number on the left under `punished` is the failure count that triggers that duration. To disable automatic challenges, set `enabled` under `anti-afk-fishing` to `false`.

## Leaderboard and personal statistics

```yaml
settings:
  leaderboard:
    # Display the event leaderboard.
    enabled: true
    # Display distance in blocks, number of entries, and refresh interval in seconds.
    distance: 6.0
    max-entries: 10
    refresh-seconds: 60
    sneak-freeze:
      # Sneaking freezes the display so players can read it.
      enabled: true
    rank-change:
      # Format for leaderboard rank changes.
      enabled: true
      # Automatically append an indicator to each player's entry.
      append-to-entry: true
      # {change} is the number of positions changed.
      up: ' <green>(↑+{change})</green>'
      down: ' <red>(↓-{change})</red>'
      unchanged: ''
      new: '<green>♦</green>'
    score-format:
      # {value} is the raw score.
      catches: '<yellow>{value}</yellow> <white>fish</white>'
      size: '<yellow>{value}</yellow> <white>cm</white>'
      bait: '<yellow>{value}</yellow> <white>bait</white>'
    # Compose leaderboard lines; available placeholders include eventName, player_1..10,
    # fish_1..10, score_1..10, position, when, rankChange_1..10.
    line:
      - '<dark_aqua><bold>Fishing Leaderboard</bold></dark_aqua>'
      - '<white>{player_1}</white> - <aqua>{fish_1}</aqua> - {score_1}'
      - '<gray>Your position: #{position}</gray>'
      - '<gray>Refreshes in {when}</gray>'
    personal-stats:
      # Personal statistics panel beside the leaderboard.
      enabled: true
      # Horizontal distance from the board, in blocks.
      labels-offset: 4.5
      # Placeholders: eventName, position, catches, score.
      labels:
        - '<yellow><bold>Personal Statistics</bold></yellow>'
        - '<white>Position:</white> #{position}'
        - '<white>Fish:</white> {catches}'
        - '<white>Score:</white> {score}'
        - '<only-shown-if-existed>'
        - '{pos} {fishColor}{fish} - {size}cm'
        - '</only-shown-if-existed>'
      fishHistory:
        # Maximum number of recent fish to display.
        maxShown: 5
        # Symbols used for history positions.
        position:
          '1': '①'
          '2': '②'
          '3': '③'
          '4': '④'
          '5': '⑤'
```

In the `line` template, use up to ten lines according to `max-entries`. Tags and placeholders become the text shown on the board; you can change the text, but keep placeholder names if you want their values to be filled in automatically.

## Fish sizes and duration labels

```yaml
settings:
  fish-size:
    # false = whole-number sizes; true = decimal sizes.
    decimal-enabled: true
    # RANDOM selects a decimal from a range; LIST selects from decimal-values.
    decimal-mode: RANDOM
    # Decimal precision from 0 to 3 digits.
    decimal-places: 2
    # Inclusive decimal range; with two digits, 0..99 means .00 to .99.
    random-min: 0
    random-max: 99
    # Decimal values for LIST mode; with two digits, 5 means .05.
    decimal-values: [0, 5, 15, 95]
    # Remove trailing zeroes, for example, 8.50 becomes 8.5.
    trim-trailing-zeroes: true

  # Labels for remaining time units. Replace these abbreviations with full words if desired.
  time-units:
    second: 's'
    seconds: 's'
    minute: 'm'
    minutes: 'm'
    hour: 'h'
    hours: 'h'
    day: 'd'
    days: 'd'
    week: 'w'
    weeks: 'w'
    month: 'mo'
    months: 'mo'
    year: 'y'
    years: 'y'
```

`decimal-mode` accepts `RANDOM` or `LIST`. `decimal-places` accepts `0`, `1`, `2`, or `3`. In `LIST` mode, values with a different number of digits are formatted to match the selected precision.

## Data storage

```yaml
storage:
  # YAML stores data in data.yml; MYSQL stores it in a database.
  type: YAML
  mysql:
    # Database address, port, and credentials.
    host: localhost
    port: 3306
    database: minecraft
    username: root
    password: ''
    # Table name and connection pool size.
    table: fiofishing_players
    pool-size: 5
```

The `type` key under `storage` accepts `YAML` or `MYSQL`. Changing the backend does not automatically move data from `data.yml`. Back up and migrate the data first if you want to preserve player statistics.
