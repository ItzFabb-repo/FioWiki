# Commands & Permissions

The root command is `/fiofishing`. The aliases `ffishing` and `fiofishing` are enabled by default; aliases can be changed in `config.yml`.

## Player commands

| Command | Permission | Description |
| --- | --- | --- |
| `/fiofishing help` | `fiofishing.command.help` | Show command help. |
| `/fiofishing stats [player]` | `fiofishing.command.stats`; other player: `fiofishing.command.stats.other` | View fishing statistics. |
| `/fiofishing afk` | Configurable in `settings.afk-feature.permission` | Start the anti-AFK challenge when that feature is enabled. |
| `/fiofishing toggle <lootable\|fishingrod\|eventLeaderboards\|durabilityBreaks>` | Matching `fiofishing.command.toggle.*` permission | Toggle personal fishing messages, rod notices, event boards, or durability warnings. |
| `/fiofishing events` | `fiofishing.command.events` | View running or scheduled events. |
| `/fiofishing leaderboards` | `fiofishing.command.leaderboards` | Open the leaderboard view. |
| `/fiofishing journey [journeys]` | `fiofishing.command.journey` | Open the fish journal. |
| `/fiofishing menu` | `fiofishing.command.menu` | Open the main menu. |
| `/fiofishing sell` | `fiofishing.command.sell` | Open the fish selling menu. |
| `/fiofishing shop` | `fiofishing.command.shop` | Open the fishing shop. |
| `/fiofishing modify <leaderboard\|personalstats> <background\|textBackground\|textColor> <value>` | Matching `fiofishing.command.modify.*` permission | Change a personal display color or reset it. |

The default player permissions are enabled by default in `plugin.yml`. A permissions plugin can override them. The four toggle permissions are `fiofishing.command.toggle.lootable`, `fiofishing.command.toggle.fishingrod`, `fiofishing.command.toggle.eventleaderboards`, and `fiofishing.command.toggle.durabilitybreaks`.

For `/fiofishing modify`, use a hex color such as `#2ee6a6`, `transparent`, or `reset`. The relevant permissions are `fiofishing.command.modify.leaderboard.background`, `.textbackground`, `.textcolor` and the corresponding `fiofishing.command.modify.personalstats.*` nodes.

## Administrator commands

Administrator actions use `/fiofishing admin` and require `fiofishing.admin` or the specific `fiofishing.admin.command.<action>` node. These permissions are operator-only by default.

| Command | Purpose |
| --- | --- |
| `/fiofishing admin help` | List administrator commands. |
| `/fiofishing admin reload` | Reload configuration, fish, bait, rods, menus, language, storage and events. |
| `/fiofishing admin permissions` | Show permission nodes. |
| `/fiofishing admin author` | Show plugin author information. |
| `/fiofishing admin placeholders` | List supported placeholders. |
| `/fiofishing admin menu forceopen <player> <Menu/path.yml>` | Force a player to open a menu file. |
| `/fiofishing admin give <baits\|fishingrods\|fish> <id> <player> [amount]` | Give a configured item. IDs come from the matching YAML file. |
| `/fiofishing admin blacklist <add\|remove\|list> ...` | Manage the fishing blacklist. |
| `/fiofishing admin region <wand\|pos1\|pos2\|create\|remove\|list\|teleport> ...` | Manage plugin fishing regions. |
| `/fiofishing admin freeze <player>` / `unfreeze <player>` | Freeze or unfreeze a player's fishing. |
| `/fiofishing admin clearplayer <player> --confirm` | Clear a player's stored fishing data. This action is destructive. |
| `/fiofishing admin events <start\|freeze\|stop\|list\|running> ...` | Manage fishing events. |

The permission `fiofishing.bypass.anti-afk-fishing` bypasses the anti-AFK fishing challenge and is operator-only by default. The AFK command permission and bypass node can also be configured in `config.yml`.

## Permission nodes

| Permission | Default | Use |
| --- | --- | --- |
| `fiofishing.use` | true | General access to fishing features. |
| `fiofishing.command.help` | true | Help command. |
| `fiofishing.command.afk` | true | AFK challenge command (subject to configuration). |
| `fiofishing.command.stats` | true | View own stats. |
| `fiofishing.command.stats.other` | true | View another player's stats. |
| `fiofishing.command.events`, `.leaderboards`, `.journey`, `.menu`, `.sell`, `.shop` | true | Open corresponding feature. |
| `fiofishing.admin` | op | All administrator actions. |
| `fiofishing.admin.command.*` | op | Individual administrator action nodes. |
| `fiofishing.bypass.anti-afk-fishing` | op | Bypass anti-AFK fishing challenge. |
