# Developer API

BetterFioExtensions does not expose a separate public Java API package like some Fio plugins. Integration is currently done through Bukkit/Spigot runtime behavior, commands, menu actions, PlaceholderAPI rendering, Vault, and BetterTeams.

## Integration points

| Integration | Usage |
| --- | --- |
| BetterTeams | Required dependency. Team objects, ranks, money, level, members, homes, warps, invites, and permissions are read or changed through BetterTeams behavior. |
| PlaceholderAPI | Optional soft-dependency. Menu text can resolve external PlaceholderAPI placeholders. |
| Vault | Optional soft-dependency. Used for player balance and team bank deposit/withdraw flows when available. |
| Bukkit commands | Menu actions can dispatch `[PLAYER]` and `[CONSOLE]` commands. |
| Bukkit events | The extension listens for inventory clicks, player commands, join/quit state, chat prompts, and visual updates. |

## Storage files

The extension persists addon data in its own files:

- `join-requests.yml`
- `team-banners.yml`
- `team-permissions.yml`
- `team-saved-locations.yml`
- `team-bank-transactions.yml`
- `team-logs.yml`

## For external plugins

Use commands or BetterTeams' own API for most automation. BetterFioExtensions-specific flows are best triggered by:

```txt
/bfe admin open [player] [menu]
/bfe admin glowTeam set [team] [color]
/bfe admin bannerTeam set [team] [num]
```

:::info[Page note]
This page is intentionally an integration note. The scanned source does not register a standalone `BetterFioExtensionsApi` service.
:::
