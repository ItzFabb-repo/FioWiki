# Actions

BetterFioExtensions menu files execute actions from YAML under `actions`.

```yaml
actions:
  any:
    - '[SOUND] UI_BUTTON_CLICK 1 1 master'
    - '[OPEN_MENU] teamMenu'
```

## Click keys

Supported click sections:

| Key | Meaning |
| --- | --- |
| `any` | Any click. |
| `left` | Normal left click. |
| `right` | Normal right click. |
| `shift_left` | Shift left click. |
| `shift_right` | Shift right click. |
| `shift` | Any shift click. |

## Base action tags

| Action | Description |
| --- | --- |
| `[NONE]` | Do Nothing. |
| `[MESSAGE]` | Send a colored message to the player. |
| `[TITLE]` | Send title text. |
| `[SUBTITLE]` | Send subtitle text. |
| `[ACTIONBAR]` | Send actionbar text. |
| `[PLAYER]` | Run a command as the player. |
| `[CONSOLE]` | Run a command as console. |
| `[SOUND]` | Play a Bukkit sound. |
| `[GOBACK]` | Return to the previous BetterFioExtensions menu. |
| `[OPEN_MENU]` | Open a configured extension menu. |
| `[CHATPROMPT]` | Open a configured chat prompt. |

## BetterFioExtensions actions

### Navigation and pages

| Action | Description |
| --- | --- |
| `[BETTERFIOEXTENSIONS] PREVIOUS_PAGE` | Move to the previous generated page. |
| `[BETTERFIOEXTENSIONS] NEXT_PAGE` | Move to the next generated page. |
| `[BETTERFIOEXTENSIONS] SORT` | Cycle the current menu sort mode. |
| `[BETTERFIOEXTENSIONS] FILTER` | Cycle the current ally request filter. |
| `[BETTERFIOEXTENSIONS] GUIDE_SORT` | Cycle the team guide view. |

### Team creation and requests

| Action | Description |
| --- | --- |
| `[BETTERFIOEXTENSIONS] CREATE_TEAM` | Start the create-team flow. |
| `[BETTERFIOEXTENSIONS] REQUEST_JOIN %team%` | Send a join request to the selected team. |
| `[BETTERFIOEXTENSIONS] ACCEPT_INVITATION` | Accept the selected team invitation. |
| `[BETTERFIOEXTENSIONS] ACCEPT_REQUEST` | Accept the selected join request. |
| `[BETTERFIOEXTENSIONS] DENY_REQUEST` | Deny the selected join request. |
| `[BETTERFIOEXTENSIONS] TEAM_INVITE_PROMPT` | Start the invite-player prompt from the team menu. |

### Team menu actions

| Action | Description |
| --- | --- |
| `[BETTERFIOEXTENSIONS] TEAM_LOGO` | Run the configured team logo interaction. |
| `[BETTERFIOEXTENSIONS] MANAGE_DESCRIPTION` | Start editing the team description. |
| `[BETTERFIOEXTENSIONS] MANAGE_RENAME` | Start editing the team name. |
| `[BETTERFIOEXTENSIONS] TEAM_PVP_TOGGLE` | Toggle team PVP. |
| `[BETTERFIOEXTENSIONS] TEAM_OPEN_TOGGLE` | Toggle public join state. |
| `[BETTERFIOEXTENSIONS] TEAM_HEAD_BANNER_TOGGLE` | Toggle head banner visibility. |
| `[BETTERFIOEXTENSIONS] TEAM_GLOW_VIEW_TOGGLE` | Toggle glow view visibility. |

### Color and glow

| Action | Description |
| --- | --- |
| `[BETTERFIOEXTENSIONS] TEAM_GLOW` | Open the team glow picker. |
| `[BETTERFIOEXTENSIONS] SELECT_COLOR %betterfioextensions_picker_color_id%` | Select the generated team color option. |
| `[BETTERFIOEXTENSIONS] SELECT_GLOW %betterfioextensions_picker_color_id%` | Select the generated glow color option. |
| `[BETTERFIOEXTENSIONS] CLEAR_GLOW_EFFECT` | Clear the active team glow effect. |

### Members

| Action | Description |
| --- | --- |
| `[BETTERFIOEXTENSIONS] MANAGE_PLAYER %player_name%` | Open management actions for the selected member. |
| `[BETTERFIOEXTENSIONS] KICK %player_name%` | Kick the selected player from the team. |
| `[BETTERFIOEXTENSIONS] BAN %player_name%` | Ban the selected player from the team. |
| `[BETTERFIOEXTENSIONS] UNBAN %player_name%` | Unban the selected player. |
| `[BETTERFIOEXTENSIONS] PROMOTE %player_name%` | Promote the selected team member. |
| `[BETTERFIOEXTENSIONS] DEMOTE %player_name%` | Demote the selected team member. |

### Saved locations

| Action | Description |
| --- | --- |
| `[BETTERFIOEXTENSIONS] TELEPORT_TEAM_ANCHOR` | Teleport to the team anchor. |
| `[BETTERFIOEXTENSIONS] SET_TEAM_ANCHOR` | Save the current location as the team anchor. |
| `[BETTERFIOEXTENSIONS] TELEPORT_TEAM_WARP %warp%` | Teleport to the selected team warp. |
| `[BETTERFIOEXTENSIONS] DELETE_TEAM_WARP %warp%` | Delete the selected team warp. |

### Allies

| Action | Description |
| --- | --- |
| `[BETTERFIOEXTENSIONS] SEND_ALLY_REQUEST %team%` | Send an ally request to the selected team. |
| `[BETTERFIOEXTENSIONS] ACCEPT_ALLY_REQUESTS` | Accept the selected ally request. |
| `[BETTERFIOEXTENSIONS] VIEW_ALLIED` | Show allied teams. |
| `[BETTERFIOEXTENSIONS] VIEW_PENDING` | Show pending ally requests. |

:::info[Page note]
The BetterFioExtensions action list above follows the formats used in `src/main/resources/menu`.
:::
