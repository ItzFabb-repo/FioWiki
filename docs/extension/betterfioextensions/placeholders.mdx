# Placeholders

BetterFioExtensions uses placeholders inside its own menu renderer and can also pass text through PlaceholderAPI when PlaceholderAPI is installed.

## Common placeholders

| Placeholder | Description |
| --- | --- |
| `%betterfioextensions_team_name%` | Current team name, formatted with BetterTeams color where available. |
| `%betterfioextensions_team_members%` | Current member count display. |
| `%betterfioextensions_team_members_total%` | Total members in generated member menus. |
| `%betterfioextensions_team_open%` | Team public/private state. |
| `%betterfioextensions_team_rank%` | Player's team rank. |
| `%betterfioextensions_team_money%` | Team money/bank value. |
| `%betterfioextensions_team_money_short%` | Compact team money value. |
| `%betterfioextensions_team_score%` | Team score. |
| `%betterfioextensions_team_kills%` | Team kills. |
| `%betterfioextensions_team_deaths%` | Team deaths. |
| `%betterfioextensions_team_bank_limit%` | BetterTeams bank limit display. |
| `%betterfioextensions_player_balance%` | Player balance through Vault. |
| `%betterfioextensions_player_total_invitations%` | Player invitation count. |
| `%betterfioextensions_requests_total%` | Pending join request count. |
| `%betterfioextensions_page_current%` | Current page number. |
| `%betterfioextensions_page_max%` | Max page number. |

## BetterTeams and PlaceholderAPI

Menus can also include external placeholders such as:

```txt
%betterteams_level%
%betterteams_score%
%betterteams_money%
%changeoutput_equals_input:{betterteams_open}_matcher:true_ifmatch:Public_else:Private%
```

:::info[Page note]
Most `betterfioextensions` placeholders are internal menu placeholders. They are not documented as a separate PlaceholderAPI expansion in the scanned source.
:::
