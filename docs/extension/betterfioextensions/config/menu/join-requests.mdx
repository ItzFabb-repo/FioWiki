# joinRequests.yml

`menu/Team Menu/joinRequests.yml` shows pending join requests for team staff.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>JOIN REQUESTS"
rows: 6

items:
  request:
    slots: []
    actions:
      left:
        - "[BETTERFIOEXTENSIONS] ACCEPT_REQUEST"
      right:
        - "[BETTERFIOEXTENSIONS] DENY_REQUEST"
```

## How to use

Use this menu for reviewing join requests. Keep accept and deny actions on the generated request item so staff can approve or reject the clicked request.
