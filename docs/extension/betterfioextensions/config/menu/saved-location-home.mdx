# savedLocationHome.yml

`menu/Team Menu/Saved Location/savedLocationHome.yml` displays team home state.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>TEAM HOME"
rows: 5

items:
  remove:
    actions:
      any:
        - "[OPEN_MENU] confirmHomeRemove"
```

## How to use

Use this menu to show whether the team home exists and to open the home removal confirmation menu.
