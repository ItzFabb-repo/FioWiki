# score.yml

`menu/Team Menu/Leaderboard/score.yml` renders the score leaderboard.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>SCORE LEADERBOARD"
rows: 6
items:
  entry:
    slots: []
  sort:
    actions:
      any:
        - "[BETTERFIOEXTENSIONS] SORT"
```

## How to use

Use this menu to style generated score entries. Keep sort and page controls unchanged.
