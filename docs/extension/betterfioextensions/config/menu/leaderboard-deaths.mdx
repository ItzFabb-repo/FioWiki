# deaths.yml

`menu/Team Menu/Leaderboard/deaths.yml` renders the deaths leaderboard.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>DEATHS LEADERBOARD"
rows: 6
items:
  entry:
    slots: []
  sort:
    actions:
      any:
        - "[BETTERFIOEXTENSIONS] SORT"
```

## How to use

Use this menu to style generated death ranking entries. Keep sort and pagination actions.
