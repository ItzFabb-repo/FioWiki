# Team Menu

`menu/Team Menu/teamMenu.yml` is the main menu for players who already have a BetterTeams team.

## Role sections

The bundled file contains:

```yaml
DEFAULT: {}
ADMIN: {}
OWNER: {}
```

The extension opens the section matching the player's BetterTeams rank.

## Common entries

| Item | Description |
| --- | --- |
| `home` | Opens saved location menu. |
| `permissions` | Opens per-team permissions. |
| `leaderboard` | Opens leaderboard category. |
| `echest` | Runs BetterTeams ender chest command. |
| `teamguide` | Opens team guide. |
| `members` | Opens member list. |
| `settings` or `controlpanel` | Opens team settings/control panel. |
| `warp` | Opens team warp list. |
| `bank` | Opens team bank. |
| `levels` | Opens team levels and perks. |
| `info` | Shows team info/logo/banner interaction. |
| `chat` | Switches chat channel. |

## Staff and owner entries

Admins and owners gain more management buttons:

- join requests
- invite player prompt
- team logs
- team ally requests
- disband confirmation
- control panel
- team banner styling

## Dynamic item states

Some menu items use state maps:

```yaml
material:
  noRequests: {}
  hasRequests: {}
```

The source chooses the item variant based on live state, such as pending invitations or join requests.

:::info[Page note]
Team menu entries often use BetterTeams placeholders and BetterFioExtensions placeholders together.
:::
