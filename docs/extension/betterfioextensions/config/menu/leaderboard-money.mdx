# money.yml

`menu/Team Menu/Leaderboard/money.yml` renders the money leaderboard.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>MONEY LEADERBOARD"
rows: 6
items:
  entry:
    slots: []
  sort:
    actions:
      any:
        - "[BETTERFIOEXTENSIONS] SORT"
```

## How to use

Edit generated entry display only. Keep `SORT`, `PREVIOUS_PAGE`, and `NEXT_PAGE` for leaderboard navigation.
