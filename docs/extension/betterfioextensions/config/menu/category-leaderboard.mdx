# categoryLeaderboard.yml

`menu/Team Menu/Leaderboard/categoryLeaderboard.yml` is the leaderboard category menu.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>TEAM LEADERBOARD"
rows: 5
commands: []

items:
  money:
    actions:
      any:
        - "[OPEN_MENU] money"
```

## How to use

Use this menu as a hub. Buttons should open `money`, `score`, `kills`, `deaths`, or `members`.
