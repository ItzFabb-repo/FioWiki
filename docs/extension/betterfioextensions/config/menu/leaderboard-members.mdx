# members.yml

`menu/Team Menu/Leaderboard/members.yml` renders the members leaderboard.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>MEMBERS LEADERBOARD"
rows: 6
items:
  entry:
    slots: []
  sort:
    actions:
      any:
        - "[BETTERFIOEXTENSIONS] SORT"
```

## How to use

Use this menu to style generated member-count ranking entries. Keep sort and pagination actions.
