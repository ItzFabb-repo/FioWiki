# teamLogs.yml

`menu/Team Menu/teamLogs.yml` displays team activity log entries.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>TEAM LOGS"
rows: 6

items:
  log:
    slots: []
  previous:
    actions:
      any:
        - "[BETTERFIOEXTENSIONS] PREVIOUS_PAGE"
```

## How to use

Edit the generated log item to change activity log presentation. Keep pagination actions so players can move through stored team logs.
