# kills.yml

`menu/Team Menu/Leaderboard/kills.yml` renders the kills leaderboard.

## YAML format

```yaml
title: "<black><bold>| <dark_gray>KILLS LEADERBOARD"
rows: 6
items:
  entry:
    slots: []
  sort:
    actions:
      any:
        - "[BETTERFIOEXTENSIONS] SORT"
```

## How to use

Use this menu to style generated kill ranking entries. Keep sort and pagination actions.
