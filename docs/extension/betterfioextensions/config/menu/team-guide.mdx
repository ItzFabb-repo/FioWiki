# teamGuide.yml

`menu/Team Menu/teamGuide.yml` explains role capabilities to team members.

## YAML format

```yaml
settings: {}

DEFAULT:
  title: "<title>"
  rows: 6
  items: {}

ADMIN: {}
OWNER: {}
```

## How to use

Edit each role section separately. Use `[BETTERFIOEXTENSIONS] GUIDE_SORT` if you want players to cycle the guide view.
